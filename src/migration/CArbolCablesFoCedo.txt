PROPÓSITO
---------
Componente GUI del sistema GIS de fibra óptica de Smallworld que presenta un
árbol jerárquico interactivo para seleccionar cables de FO conectados a una
central óptica (CEDO) dentro del diseño activo.

La jerarquía del árbol es:
  Distrito óptico
    └── CEDO (Centro de Distribución Óptica)
          └── Cable de FO (con checkbox de selección)

El usuario marca exactamente UN cable, luego pulsa "Generar Plano de Cable
Seleccionado" para lanzar el motor de planos (c_engine_ruta_cables +
c_plano_diagrama_de_empalmes). Si la selección no es válida, se muestra un
error. "Salir" cierra el diálogo sin acción.

  empalme_seleccionado  → empalmeSeleccionado: CableItem[]
                          Rope vacío por defecto (rope.new()).
                          Reservado para lista de empalmes (deshabilitado en orig.)

COLORES EN EL ÁRBOL
--------------------
Magik usa styled_string con estilos nombrados:
  :green_bold → nodos EXISTENTE (Distrito y CEDO)
  :red        → nodos PROYECTADO (Distrito y CEDO)
  :green + :toggle :check → cables EXISTENTE con checkbox
  :red   + :toggle :check → cables PROYECTADO con checkbox

En TypeScript:
  EXISTENTE  → color #a6e3a1 (verde) + badge verde
  PROYECTADO → color #f38ba8 (rojo) + badge rojo

DIFERENCIAS RESPECTO AL MAGIK ORIGINAL
----------------------------------------
· :model (framework Smallworld) no está migrado. La clase TypeScript
  gestiona estado directamente sin framework de modelo.

· tree_item (widget nativo) → árbol recursivo React con NodeView.
  La expansión/colapso y los checkboxes son React state.

· string_styles_holder / font.new_logical → estilos CSS inline.

· swg_dsn_admin_engine.active_design → MOCK_DISTRITO con 3 CEDOs y 7 cables.
  En producción, vendría del servicio GIS activo.

· get_downstream_cables() → mock que devuelve los cables del CEDO directamente.

· c_engine_ruta_cables.new() + c_plano_diagrama_de_empalmes.genera_plano()
  → stub que devuelve mensaje de confirmación. No hay motor de planos real.

· set_children_method para empalmes (llena_empalmes) está comentado en el
  original (bflores, 14/10/08). Se preserva esa omisión — los cables son hojas.

· rowcol / button_box → layout CSS flex (display:flex, justify:flex-end).

· El componente UI añade:
  - Contador de cables marcados con indicación de validez
  - Mensajes de error/éxito inline
  - Botón "Reabrir" cuando el diálogo está cerrado
  - Leyenda de iconos (▣ Distrito ◈ CEDO ○ Cable)
