PROPÓSITO
---------
Modelo de dominio "Distrito" para planos de canalización Smallworld PNI.
Lee datos de la BD landbase (mockeada en TS) y agrega por NSE
(Nivel Socio-Económico):
  · número de viviendas por NSE
  · número de líneas por NSE
  · NSE predominante
  · totales de viviendas y líneas
  · iniciales de cada NSE (A, B, IL, IM, 1ª, 2ª, LB, …)

Se utiliza desde los sellos (c_distrito, sello_pep_dcs, etc.) que pintan
las cifras del distrito en el plano.

TIPOS DEFINIDOS (D5 — XxxRecord para campos user!_*)
------------------------------------------------------
NSE
  Unión literal con los 12 niveles socio-económicos del enumerador
  :user!_nivel_socio (RESIDENCIAL A..E, COMERCIAL 1..3, INDUSTRIAL
  LIGERA/MEDIANA/PESADA, LOTE BALDÍO).

NSE_SORTED  : readonly NSE[]
  Equivale a .type.enumerator.sorted_values.elements().

DistritoRecord
  { 'user!_distrito': string; 'user!_limite': string }

DetalleLoteRecord
  { 'user!_nivel_socio': NSE; 'user!_cantidad_servicios': number }

LoteRecord
  { 'user!_lote': string;
    'user!_distrito_ref': string;
    'user!_limite': string;
    'user!_detalle_lotes': DetalleLoteRecord[] }

MockLandbaseDB
  { distritos: DistritoRecord[];
    lotes: LoteRecord[];
    detalleLote?: DetalleLoteRecord[] }

DIFERENCIAS RESPECTO AL MAGIK ORIGINAL
----------------------------------------
· La BD landbase Smallworld no existe en navegador. Se modela con
  MockLandbaseDB en memoria. Inyectable por constructor para tests.

· predicate.within(:user!_limite, oDto.user!_limite) se reduce a una
  comparación literal sobre el string "POLY-NNN" (mock). En el original
  es contención geométrica real.

· `_self.collDet_Lote` se rellena en prvLeer_Distrito_BdD() incluso si
  el distrito no existe (igual que el Magik). Si la BD mock no expone
  `detalleLote` explícito, se construye flat-mapping todos los lotes.

· La clase no se instancia con `new()`/`init()` (regla D2 del CLAUDE.md
  global). Se usa constructor TS estándar. El método estático version()
  se conserva.

· Bug del Magik: sTotal_Viviendas chequea `.sTotal_Lineas _is _unset`
  en lugar de `.sTotal_Viviendas _is _unset`. Se preserva el chequeo
  (ambos totales se rellenan a la vez, así que es equivalente funcional).

· Multi-return Magik (LcollViv, LcollLin) → objeto { viv, lin } en TS.

· numero_Viviendas_NSE / numero_Lineas_NSE devuelven una unión
  Map<NSE,number> | string. La UI hace `instanceof Map` para discriminar.

· La UI añade:
  · Selector con 3 distritos válidos + 1 inválido (DTO-INEXISTENTE)
  · Pill "existe? / no existe" para visualizar prvValida_Distrito()
  · Tabla "viviendas / líneas por NSE" filtrada a NSE con datos
  · Listado de lotes con detalle (NSE×servicios) y suma
  · Cabecera con CDistritoE.version()
