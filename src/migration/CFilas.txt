PROPÓSITO
---------
Contenedor 1D de filas (c_fila) del motor de plotting (layout / sellos) de
Smallworld. Mantiene N filas indexadas por número entero (1-based), cada una
con su nLongitud (altura/grosor en décimas de mm — la conversión ×10 vive
en c_fila / CFila).

Es la pieza superior de tabla del layout: la c_celdas usa la cuadrícula
(ren × col) y c_filas mantiene la dimensión vertical (altura de cada
renglón). Su responsabilidad principal:

  1. Crear N filas con longitud por defecto → new(RnTot_Filas)
  2. Acceder a una fila concreta             → elemento(RnFila)
  3. Calcular offset Y de una fila           → Inicia_Elemento(N)
  4. Calcular altura total                   → Longitud_Total()
  5. Serialización slotted (init_with / new_from_serial / serial_slots)


SLOTS MIGRADOS (estado interno)
---------------------------------
  nTotal_Filas → _nTotal_Filas: number
                 Número total de filas del contenedor.
                 Setter público con validación >0 (lanza RangeError).

  collFilas    → _collFilas: Map<number, CFila>
                 hash_table.new() en Magik → new Map<number, CFila>().
                 Clave: número de fila (1-based). Valor: instancia CFila.

  nLong_Total  → _nLong_Total: number    (:private en Magik)
                 Longitud total cacheada (no se recalcula automáticamente —
                 lo gestiona el sistema externo). Acceso vía getter/setter
                 protected con validación >0.


MÉTODOS MIGRADOS (14)
---------------------

1. constructor(RnTot_Filas)
   Magik: new(RnTot_Filas)
       _local LnLong << 10
       _self.nTotal_Filas << RnTot_Filas      (pasa por setter → valida >0)
       _self.collFilas << hash_table.new()
       _for LnNum_Fila _over range(1, _self.nTotal_Filas)
       _loop _self.collFilas[LnNum_Fila] << c_fila.new(LnLong) _endloop
       _return _clone
   Crea Map vacío, asigna nTotal_Filas pasando por su setter (que valida >0
   y lanza si recibe 0), luego construye N CFila(10) e indexa en 1..N.

2. elemento(RnFila)
   Magik:
       _if RnFila <= 0 _and RnFila > _self.nTotal_Filas
       _then condition.raise(:warning, ...) _endif
       >> _self.collFilas[RnFila]
   Devuelve la CFila en posición RnFila.
   IMPORTANTE: la condición original usa AND donde lógicamente debería ser
   OR — el bug está en el .magik, no en la migración. Se replica fielmente
   (la rama de error nunca se ejecuta porque la condición jamás es true).

3. Inicia_Elemento(RnNum_Elemento)
   Magik:
       LnLong << 0
       _for LnFila _over range(1, RnNum_Elemento-1)
       _loop LnLong << _self.collFilas[LnFila].nLongitud + LnLong _endloop
       _return LnLong
   Devuelve el pixel/offset donde inicia la fila RnNum_Elemento, sumando
   las longitudes de todas las filas anteriores (1..N-1). Es el cálculo
   acumulado 1D que usa el motor para posicionar verticalmente la fila i.
   range(a,b) en Magik es inclusivo en ambos extremos → for i=1; i<=N-1; i++.

4. Longitud_Total()
   Magik:
       LnLong_Total << 0
       _for LnFila _over range(1, _self.nTotal_Filas)
       _loop LnLong_Total << _self.collFilas[LnFila].nLongitud + LnLong_Total _endloop
       _return LnLong_Total
   Suma todas las nLongitud → altura total del contenedor (en décimas de mm).

5. Total_Elementos()
   Magik: >> _self.nTotal_Filas
   Alias de getter de nTotal_Filas. Se exportan ambos por compatibilidad.

6. get / set nTotal_Filas
   Magik:
       _method c_filas.nTotal_Filas → getter
       _method c_filas.nTotal_Filas << RnValor
           _if RnValor > 0 _then .nTotal_Filas << RnValor
           _else condition.raise(:warning, :string, "Error al asignar...")
   Setter público con validación: throw RangeError si <=0.

7. get / set collFilas
   Magik:
       define_slot_access(:collFilas, :writable)
       _method c_filas.collFilas << filas
   Lectura del Map y reemplazo completo.

8. protected get nLong_Total / setNLongTotal(valor)
   Magik:
       _private _method c_filas.nLong_Total → getter
       _private _method c_filas.nLong_total << valor
           _if valor > 0 _then .nLong_total << valor _endif
   Slot :private en Magik (solo accesible desde _self).
   En TS: getter protected + método setNLongTotal con validación >0
   (silenciosa: si <=0 no asigna y no lanza, fiel al magik).

9. initWith(props)
   Magik: init_with(props)
       _for key, value _over props.fast_keys_and_elements()
       _loop
           _try _with cond
                _self.perform_private(key.with_chevron, value)
           _when does_not_understand _endtry
       _endloop
       _return _self
   Asignación dinámica por nombre de slot. perform_private +
   does_not_understand → en TS se mapea con if (props.key !== undefined)
   por cada slot conocido + try/catch sobre el setter público (que valida).
   Devuelve this (método fluent).

10. static fromSerial(keys, xmlValues)
    Magik: new_from_serial(keys, xml_values)
        props << property_list.new()
        _for nr, key _over keys.fast_keys_and_elements()
        _loop props[key] << xml_values[nr] _endloop
        _return _clone.init_with(props)
    Empareja keys[i] ↔ xmlValues[i] en un Record y crea nueva instancia
    con N filas, luego invoca initWith para sobrescribir slots.

11. serialSlots()
    Magik: serial_slots()
        _local ln_long
        _try ln_long << .nLong_Total/10
        _when does_not_understand ln_long << 0 _endtry
        keys   << rope.new_with(:nTotal_Filas, :collFilas, :nLong_Total)
        values << rope.new_with(.nTotal_Filas, .collFilas, .nLong_Total)
        >> keys, values
    Devuelve { keys, values, nLongDecimm } donde nLongDecimm es nLong_Total/10
    (conversión a mm — equivale a la variable local ln_long que el magik
    calculaba pero no devolvía explícitamente; se expone aquí para fidelidad).

12. static serialStructure()
    Magik: serial_structure → >> :slotted
    Indica el tipo de estructura: 'slotted'.

13. private _buildRows()
    No es método Magik público — encapsula el bucle de creación de CFila
    en new(). Equivale al _for LnNum_Fila _over range(1, _self.nTotal_Filas)
    _loop _self.collFilas[LnNum_Fila] << c_fila.new(10) _endloop.


DEPENDENCIA: CFila
-------------------
CFilas usa CFila importado de './CFila'. CFila almacena su nLongitud
internamente ×10 (mm externos → décimas de mm internas) — esa conversión
NO la hace c_filas, la hace c_fila. Por eso:

  · new CFila(10)            → _nLongitud interno = 100
  · fila.nLongitud (getter)  → devuelve 100
  · fila.nLongitud = 15      → setter convierte → _nLongitud = 150

Las sumas de Longitud_Total() / Inicia_Elemento() trabajan con el valor
del getter (×10), idéntico al magik original.


MAPEO MAGIK → TYPESCRIPT
--------------------------
  def_slotted_exemplar          → class CFilas
  define_slot_access(:writable) → campo private + getter/setter public
  _private _method              → protected getter + método "set*"
  hash_table.new()              → new Map<number, CFila>()
  hash_table[k] << v            → map.set(k, v)
  hash_table[k]                 → map.get(k)
  rope.new_with(...)            → array literal [...]
  property_list.new()           → {} (Record<string, unknown>)
  range(1, N)                   → for (let i = 1; i <= N; i++)
  range(1, N-1)                 → for (let i = 1; i <= N - 1; i++)
  condition.raise(:warning,...) → throw new RangeError(...)
  _try / _when does_not_understand → try { … } catch { /* swallow */ }
  perform_private(k<<, v)       → asignación directa al campo + try sobre setter
  _return _clone                → new CFilas(...) + initWith()
  >> _self.collFilas[i]         → return this.collFilas.get(i)
  >> :slotted                   → return 'slotted' as const


NO HAY GEOMETRÍA — POR QUÉ
----------------------------
c_filas es contenedor 1D puro. No realiza intersecciones, buffers ni
manipulación cartográfica → no se necesita Turf.js ni OpenLayers en esta
clase. La sustancia geométrica entra cuando un layout consume:

    Inicia_Elemento(i)  → offset Y de la fila i (en décimas de mm)
    + el oArea/bbox del contenedor padre (p.e. c_elementos)
    → cálculo del rect [x0, y0+offset, x0+ancho, y0+offset+nLongitud]

Ese cálculo lo hace el layout (p.e. c_tabla, c_celdas_grafico), no c_filas.
Si en algún momento se quiere visualizar el resultado, el caller hará:

    const offsetY = filas.Inicia_Elemento(fila);
    const h       = filas.elemento(fila).nLongitud;
    const rect    = fromExtent([x0, y0 + offsetY, x1, y0 + offsetY + h]);
    vectorSource.addFeature(new ol.Feature({ geometry: rect }));


DIFERENCIAS RESPECTO AL MAGIK ORIGINAL
----------------------------------------
· elemento(RnFila): se replica el bug AND (debería ser OR). La validación
  nunca lanza en el .magik original; lo respetamos en TS para preservar
  semántica exacta. El error está documentado en el código.

· nLong_Total es :private en Magik con setter que ignora silenciosamente
  valores <=0. En TS se expone como protected con setNLongTotal — sin
  lanzar, fiel al "_if valor > 0 _then …" sin else.

· init_with() usa perform_private(key.with_chevron, value) — en Magik es
  reflexión por nombre de slot. En TS se mapea con if (props.key !== undefined)
  por cada slot conocido. La protección try/catch sobre el setter público
  emula el _try _when does_not_understand del magik.

· new_from_serial() devuelve _clone (nueva instancia) en Magik. En TS se
  crea new CFilas(nTot) explícitamente antes de llamar initWith, lo que
  re-ejecuta _buildRows() — initWith puede sobrescribir collFilas si los
  datos serializados contienen filas previas.

· serial_slots() en Magik calculaba ln_long << .nLong_Total/10 pero NO lo
  devolvía en el rope. Aquí lo exponemos como nLongDecimm en el resultado
  para que sea aprovechable.

· serial_structure() es instance method en Magik; en TS es static (no
  depende del estado).
