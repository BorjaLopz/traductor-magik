=============================================================================
PROPÓSITO
=============================================================================
Elemento de layout que inicializa una página completa de plano GIS.
Según el atributo sTipoPlano crea: marco, viewport mapeado, norte y sello
correspondiente. Soporta 10 tipos de plano:
  DISTRITOS / ASHURADO / CANALIZACION / ITINERARIO / RUTA_CABLES /
  Plano_desmontaje_CD / Physical NI User / CONSTRUCCION / BAJANTES / ESTUDIO_CONJUNTO

=============================================================================
DECISIONES DE DISEÑO
=============================================================================

PageLayout como return type de initializeForPage:
  En Magik el método modifica la página in-place (add_element).
  En TS retorna un objeto descripción que el componente React renderiza.
  Esto permite testear la lógica sin infraestructura SW.

TIPO_PLANO_CATALOG / TIPO_SELLO como maps:
  El Magik original es un gran if-elif chain. Se modela como dos Record<>
  para mantener la correspondencia explícita y extensible.

Extra elements:
  Algunos tipos agregan elementos adicionales (c_legend_layout_sigc,
  c_sello_capacidad_cable, c_pep, symbol_layout). Se representan como
  LayoutPageElement[] en el campo extra de PageLayout.

Viewport bounds para Plano_desmontaje_CD:
  El Magik usa bounds fijos (2540,270,xmax-270,ymax-270). Se reproduce
  exactamente con el condicional en initializeForPage.

Mapeo de viewport a central/distrito (LoViewMapperPlugin):
  No migrado: depende de swg_dsn_admin_engine, map_plugin y viewport_mapper.
  En integración real, esta responsabilidad sube al motor de planos OL.
