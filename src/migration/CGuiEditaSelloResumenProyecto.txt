PROPÓSITO
---------
Componente GUI del motor de planos (plotting engine) de Smallworld que gestiona
la edición interactiva del texto libre de un "sello resumen proyecto".

En Magik, abre una ventana (frame/text_window) sobre el plano, carga el contenido
de la celda (2,1) de la tabla "tbl_resumen_proyecto" en un área de texto, permite
que el usuario edite el texto, y al confirmar lo escribe de vuelta al sello
convertido a mayúsculas (.uppercase → .toUpperCase()), refrescando el layout.

En TypeScript, se implementa como un modal dialog (position:fixed overlay) con
un textarea editabe, botones de confirmación y cancelación, log de cambios, y
un panel de visualización del layout simulado.

En producción, loCurrentPage1 vendría del layout_view activo del plotting engine.


DIFERENCIAS RESPECTO AL MAGIK ORIGINAL
----------------------------------------
· gui_framework_mixin no está migrado. La funcionalidad GUI (frame, widgets) se
  reemplaza por un modal dialog React con position:fixed overlay.

· El text_item de Magik (widget nativo de Smallworld) se mapea a <textarea>
  con React state para gestión del valor.

· layout_view_refresh() no tiene equivalente directo. Se simula registrando
  el cambio en changeLog y forzando re-render del componente.

· define_shared_variable se convierte en campo static de clase TypeScript.
  La instancia singleton se accede via CGuiEditaSelloResumenProyecto.editaSelloResumenProyAux.

· El componente UI añade:
  - Preview del layout simulado (lista de elementos de loCurrentPage1)
  - Panel del sello activo con contenido de celda en tiempo real
  - Log de cambios (changeLog) visible en la UI
  - Display de la variable compartida editaSelloResumenProyAux
