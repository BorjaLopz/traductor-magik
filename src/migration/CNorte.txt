PROPÓSITO
---------
Símbolo de norte para planos GIS de fibra óptica (Smallworld PNI).
Se incrusta en el layout del plano como elemento gráfico vectorial.
Soporta tres tamaños (A, B, C) y se auto-rota para que la flecha
siempre apunte al norte geográfico, independiente de la orientación
del viewport del mapa.

No aparece en menús de usuario (allowed_on_menu? = false).
No abre diálogo de propiedades al insertar (activate_properties_dialog_on_insert? = false).

  ACTIVATE_PROPERTIES_DIALOG_ON_INSERT = false

SLOTS MIGRADOS
---------------
  limites → { xmin, ymin, xmax, ymax } | null   (Magik: .limites, :writable, :public)
    Bounding box del plano GIS que contiene el símbolo.
    Usado en draw_content_on() para posicionar el símbolo en la
    esquina superior-izquierda con margen de 400 unidades (≈4 cm).

  oFlag → boolean   (Magik: .oFlag, _false, :writable, :private)
    Flag interno, reseteado a false en initialise_for_page().
    No expuesto en la API pública.

5. construir_arco(PnRadio, PoCentro, PnAngIni, PnAngFin)
   → construirArco(radio, cx, cy, angIni, angFin): Pt[]
   ───────────────────────────────────────────────────────
   Genera puntos a intervalos de 1° desde angIni hasta angFin.

   Fórmula:
     x = cx + radio × cos(ang × π/180)
     y = cy + radio × sin(ang × π/180)   ← GIS: Y crece hacia arriba

   Usado para crear 4 arcos de 50° cada uno (con gaps de 40°) que forman
   un círculo punteado alrededor del símbolo:
     Tamaño A: radio 65, arcos 20-70°, 110-160°, 200-250°, 290-340°
     Tamaño B: radio 45, mismos ángulos
     Tamaño C: sin arcos


6. construir_norte(PoSecRop, PsTamano)
   → construirNorte(cx, cy, tamano): NorteGeometry
   ─────────────────────────────────────────────────
   Construye la geometría completa del símbolo de norte usando offsets
   relativos acumulados (equivalente a coordenadas + offset en Magik).

   Estructura NorteGeometry:
     arrow   : Pt[]         — polígono cerrado (flecha)
     leftH?  : [Pt, Pt]     — línea horizontal izquierda (sizes A, B)
     rightH? : [Pt, Pt]     — línea horizontal derecha (sizes A, B)
     arcs    : Pt[][]       — 4 arcos del círculo punteado (sizes A, B)
     viewBox : string       — SVG viewBox precomputado
     boundW  : number       — ancho del bounding_box Magik
     boundH  : number       — alto del bounding_box Magik

   GEOMETRÍA POR TAMAÑO (centro en origen 0,0):
   ┌────────┬────────────────────────────┬────────────────────┬───────────────────┐
   │ Tamaño │ Flecha (y_gis)             │ Líneas horiz.      │ Bound (u.)        │
   ├────────┼────────────────────────────┼────────────────────┼───────────────────┤
   │ A      │ −470 a +460                │ ±90 u, stroke 5    │ 60 × 960          │
   │ B      │ −350 a +320                │ ±75 u, stroke 5    │ 60 × 710          │
   │ C      │ −236 a +230  (solo flecha) │ —                  │ 50 × 500          │
   └────────┴────────────────────────────┴────────────────────┴───────────────────┘

   OFFSETS DE LA FLECHA — Tamaño A:
     p0=(5,0) → p1+=(0,460) → p2+=(-30,-230) → p3+=(20,-15) → p4+=(0,-670)
     → p5+=(30,-15) → p6+=(0,240) → p7+=(-20,10) → cierre a p0

   OFFSETS DE LA FLECHA — Tamaño B:
     p0=(5,0) → p1+=(0,320) → p2+=(-25,-170) → p3+=(15,-15) → p4+=(0,-470)
     → p5+=(30,-15) → p6+=(0,170) → p7+=(-20,10) → cierre a p0

   OFFSETS DE LA FLECHA — Tamaño C:
     p0=(2.5,0) → p1+=(0,230) → p2+=(-20,-116) → p3+=(10,-10) → p4+=(0,-330)
     → p5+=(20,-10) → p6+=(0,120) → p7+=(-10,10) → cierre a p0


7. draw_content_on(window) → buildRenderData(viewAngleDeg): { geo, rotateDeg }
   ──────────────────────────────────────────────────────────────────────────────
   Pipeline del método original:

   a) Reposicionamiento (si .limites está definido):
      LoBound = bounding_box.new(
        limites.xmin + 400,              ← margen izquierdo 400 u ≈ 4 cm
        limites.ymax − 400 − height,     ← margen superior 400 u
        limites.xmin + 400 + width,
        limites.ymax − 400
      )
      _self.bounds << LoBound
      En TS: lógica de posicionamiento delegada al caller.

   b) Construcción de geometría:
      (LcollSectores, LoBound) << _self.construir_norte(LcollSectores, _self.tamano)
      → construirNorte(0, 0, tamano)

   c) Rotación:
      LcollSectores.transformed(rotate_about(centre, −view_angle.degrees_to_radians))
      → SVG: <g transform="rotate(−viewAngleDeg)">
      Signo negativo: si el viewport está girado +30°, el norte rota −30°
      para compensar y mantener la flecha apuntando al norte real.

   d) Dibujo:
      · Todos los sectores: line_style(black, weight=2)
      · Sectores[2] y [3] (líneas horizontales): line_style(black, weight=5) — re-dibujados
      En SVG: polygon(fill=black) + line(strokeWidth=5) + polyline(strokeWidth=2)


SISTEMA DE COORDENADAS
-----------------------
  Magik GIS:  Y crece hacia arriba (Y-up)
  SVG/Pantalla: Y crece hacia abajo (Y-down)

  Conversión: y_svg = −y_gis
  Implementado en svgPts(): p => `${p.x},${−p.y}`

  La rotación SVG es en sentido horario para ángulo positivo.
  Magik usa convención matemática estándar (antihorario = positivo).
  En el slider del UI se aplica directamente rotation° al SVG transform="rotate()".


COMPONENTE REACT UI
--------------------
  CNorteUI:
  - Selector de tamaño: botones A / B / C
  - Slider de ángulo: 0–359° (simula view_angle del viewport)
  - Botón de reset (↺)
  - Vista SVG: height=280px, width auto (preserva aspect ratio del viewBox)
    · Flecha: <polygon fill="black"> — polígono cerrado
    · Líneas horizontales: <line strokeWidth={5}> (sizes A, B)
    · Círculo punteado: 4 <polyline strokeWidth={2}> (sizes A, B)
    · Todo dentro de <g transform="rotate(angle)">
  - Tabla de propiedades: allowed_on_menu, jerarquía, slots, bounds, radio, líneas
