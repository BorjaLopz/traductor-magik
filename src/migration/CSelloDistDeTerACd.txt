DESCRIPCIÓN GENERAL
-------------------
Sello del Layout Designer que presenta una cuadrícula 17×5 con las distancias
de cada terminal de cobre a la Central Distribuidora (C.D.) de un edificio.

La cuadrícula tiene:
  - 17 filas: fila 0 = cabecera (1-5), filas 1-16 = letras A-S (sin I, N, Q)
  - 6 columnas: col 0 = etiqueta de fila, cols 1-5 = distancias por terminal
  - Cabeceras en verde rgb(0,76,0), valores en rojo rgb(200,0,0)

Admite dos estrategias de carga:
  1. Búsqueda directa por edificio  (user!_building.at(idEdificio))
  2. Búsqueda por distrito óptico   (user!_distrito_optico.at(idEdificio))
     con predicate.inside(:boundary) → recorre todos los edificios del distrito

FUNCIONAMIENTO REAL
-------------------
1. UBICA_COORD (constante):
   Mapea cada ID de terminal (ej. 'A1', 'B3', 'S5') a su posición en
   tbl_contenido como { col, row }. Los valores son:
     col = número de terminal + 1  (1→2, 2→3, ..., 5→6)
     row = índice de letra + 2     (A→2, B→3, ..., S→17)
   Equivale a la constante Magik UbicaCoord con hash_table.new_with(...)
   ampliada por CompletaSharedVariable() con las filas O, P, R, S.

2. configurarTabla():
   tbl_titulo   : 1×1, renglon=5mm, columna=40mm
   tbl_contenido: 17×6
     renglones   = [5,5,...,5] × 17
     columnas    = [5, 7, 7, 7, 7, 7] mm

3. filtrarTerminalesConDist(terminals):
   Recibe los terminales de un edificio y devuelve un mapa
   ID → distancia (ej. 'A1' → '1.234').
   Equivale a iterar sobre los related_objects (copper_terminal),
   extraer user!_cuenta y user!_distancia_cd, y formatear con
   as_fixed_string(10,3).trim_spaces() → toFixed(3).
   Solo incluye terminales cuyo ID aparece en UBICA_COORD.

4. llenarDatosCeldas(idEdificio) [async]:
   Ruta 1: busca el edificio directamente por ID.
     Si existe, llama filtrarTerminalesConDist sobre sus terminales.
   Ruta 2: si no hay edificio, busca un distrito óptico por ID.
     Itera sus edificios (predicate.inside(:boundary)) y combina
     los mapas de terminales de cada uno.
   Devuelve TerminalDistMap = Record<string, string>.

5. buildGrid(distances):
   Construye la matriz 17×6 de strings:
     grid[0]     = ['', '1', '2', '3', '4', '5']  (cabeceras col)
     grid[i][0]  = letra de fila (A-S)              (cabeceras fila)
     grid[i][j]  = distancia formateada o ''         (datos)
   La posición (i,j) se obtiene de UBICA_COORD:
     gridRow = pos.row - 1   (2..17 → 1..16)
     gridCol = pos.col - 1   (2..6  → 1..5)


EQUIVALENCIAS MAGIK → TYPESCRIPT
----------------------------------
  define_shared_constant(:UbicaCoord, hash_table.new_with(:A1,coordinate(2,2),...))
    → const UBICA_COORD: Record<string, GridPos>  (generación automática)

  CompletaSharedVariable()  [filas O,P,R,S]
    → incluido en la misma generación del IIFE

  coordinate(x, y)
    → interface GridPos { col: x, row: y }

  hash_table.new()
    → Record<string, string>   (TerminalDistMap)

  rope.new_from(_super.defined_attributes) + idEdificio
    → interface SelloAtribs { idEdificio: number | null }

  gis_program_manager.cached_dataset(:gis).collections[:user!_building].at(id)
    → MOCK_BUILDINGS.find(b => b.id === id)

  gis_program_manager.cached_dataset(:landbase).collections[:user!_distrito_optico].at(id)
    → MOCK_DISTRICTS.find(d => d.id === id)

  predicate.inside(:boundary, LoReg.user!_limite) + LcollTabUserBuilding.select(pred)
    → district.buildingIds.map(bId => MOCK_BUILDINGS.find(x => x.id === bId))

  related_objects_provider.get_related_items_for(LoRecTab)
    → building.terminals  (mock GIS relation)

  LoRec.is_kind_of?(copper_terminal)
    → campo terminal.id + filtrado por UBICA_COORD

  LoRec.user!_cuenta.default("no_dato").as_symbol().canonical
    → terminal.id.toUpperCase().trim()

  LoRec.user!_distancia_cd.as_fixed_string(10,3).trim_spaces()
    → terminal.distCd.toFixed(3)

  asigna_texto_celda(:tbl_contenido, LoRenglon, LoColumna, LsDato, 15, :centre_centre, 0, {1,0,0})
    → grid[gridRow][gridCol] = distancia  (rojo rgb(200,0,0))

  LoCoord.y.integral_and_fraction()  →  pos.row  (parte entera)
  LoCoord.x.integral_and_fraction()  →  pos.col  (parte entera)

  etiqueta_celdas() cabeceras colour.new_rgb(0,0.2993,0)
    → GREEN = 'rgb(0,76,0)'  (0.2993 × 255 ≈ 76)


TABLAS DE CONFIGURACIÓN
------------------------
  tbl_titulo:
    1 renglon × 1 columna
    Renglon alto: 5 mm
    Columna ancho: 40 mm
    Texto: "DISTANCIA DE TERMINAL A C.D." (verde, centre_centre, size 25)

  tbl_contenido:
    17 renglones × 6 columnas
    Todos los renglones: 5 mm
    Columnas: [5, 7, 7, 7, 7, 7] mm
    Cabecera fila 1, col 1: vacío
    Cabecera fila 1, cols 2-6: "1","2","3","4","5"
    Cabecera col 1, filas 2-17: "A","B","C","D","E","F","G","H","J","K","L","M","O","P","R","S"
    Datos (filas 2-17, cols 2-6): distancias en km con 3 decimales
