PROPÓSITO
---------
Elemento gráfico que dibuja un símbolo del catálogo
:sw_gis!gis_point_style sobre un área dada de un sello. Soporta flip
horizontal/vertical, rotación en grados y selección entre la
sigc_style_view (vista de proyecto) o la style_view global.


SLOTS MIGRADOS (estado interno — todos :private :writable)
-----------------------------------------------------------
  :sNombre_Grafico → _sNombre_Grafico: string | undefined
                     Nombre del símbolo del catálogo (gis_point_circle,
                     gis_point_arrow, etc.).
  :bVoltear_H      → _bVoltear_H: boolean = false
                     Espejado horizontal (flipped en draw_sample).
  :bVoltear_V      → _bVoltear_V: boolean = false
                     Espejado vertical (mirror en draw_sample).
  :nGrados         → _nGrados: number = 0
                     Ángulo de rotación en grados (default 0°).
  :o_sty_view      → _o_sty_view: ':default' | string | undefined
                     Grupo de estilos. ':default' fuerza style_view global.

HEREDADOS (stub CElementoGrafico — clase padre no migrada):
  oArea:    Area | undefined
  oVentana: VentanaDibujo | undefined
  nMargen_izq / nMargen_der / nMargen_sup / nMargen_inf : number


TIPOS DEFINIDOS
----------------
Area
  { xmin, ymin, xmax, ymax: number } — equivale a bounding_box Magik.

VentanaDibujo
  { id: string } — descriptor opaco de la ventana de dibujo.

SymbolStyleRecord
  Stub del record temporal devuelto por new_detached_record() del
  catálogo. Tiene symbol_name, realise(), draw_sample().

StyleViewLike
  { collections: { 'sw_gis!gis_point_style': { new_detached_record() } } }

GisProgramManagerMock
  { databases: { sigc_style_view? }, style_view }
  Replica gpm.databases[:sigc_style_view] y gpm.style_view.

GrupoEstilos
  ':default' | string | undefined

SymbolName
  Unión literal con los 9 símbolos mockeados + (string & {}) para
  permitir nombres arbitrarios.

DrawCall
  Descriptor que devuelve Despliega() — útil para la UI sin canvas
  Smallworld real.

SimboloGraficoProps
  Extiende ElementoGraficoProps con sNombre_Grafico, bVoltear_H/V,
  nGrados, grupo_estilos.

DIFERENCIAS RESPECTO AL MAGIK ORIGINAL
----------------------------------------
· c_elemento_grafico (clase padre) NO está migrado en el showcase.
  Se incluye un stub CElementoGrafico con los slots y métodos
  mínimos (oArea, oVentana, márgenes, init_with, serial_slots) que
  la subclase necesita. Cuando se migre, importarlo de su módulo.

· Despliega() en el Magik dibuja directamente sobre la ventana
  Smallworld (.oVentana). En TS no hay canvas Magik — el método
  devuelve un DrawCall con todos los parámetros resueltos y la UI
  lo pinta con SVG + CSS transform (rotate Z + scaleX para flipped,
  scaleY para mirror). Es la representación más fiel sin acoplar
  a un renderer concreto.

· :flipped? Magik se mapea a "scaleX(-1)" (espejado horizontal).
  :mirror? se mapea a "scaleY(-1)" (espejado vertical). En Magik
  Smallworld el catálogo decide la aplicación final; aquí se hace
  composición simple — el orden de transformaciones puede diferir
  para símbolos asimétricos.

· new_from divide los márgenes entre 10. Es un bug histórico
  documentado en el propio Magik (DSB 25/01/05). Se PRESERVA porque
  la migración no corrige bugs salvo petición expresa — si en una
  pasada futura se decide eliminar, basta con suprimir las cuatro
  divisiones.

· `bVoltear_H?` y `bVoltear_V?` Magik (con ? final) se mapean a
  bVoltear_H / bVoltear_V — el ? no es válido en identificadores JS.

· Símbolos Magik (:default, :sigc_style_view) se convierten en
  strings literales (no hay símbolos en JS). Esto significa que
  ':default' en TS es una string que empieza por ':' — coincide
  visualmente con el Magik pero es comparable como string normal.

· La UI añade:
  · Selector de los 9 símbolos del catálogo mock
  · Toggles bVoltear_H? / bVoltear_V?
  · Input numérico nGrados con step=15° para rotaciones cómodas
  · Selector grupo_estilos: unset / :default / "sigc"
  · Preview SVG 180×180 con CSS transform animado
  · Tarjeta con todas las claves de serial_slots (heredadas + propias)
  · Demo new_from con un símbolo prototipo de márgenes 50 — visible
    que se reducen a 5 tras la copia (validando la regla /10)
