── QUÉ HACE ────────────────────────────────────────────────────────────────────

Patrón FACTORY: instancia el tipo correcto de elemento gráfico de tramo
(c_elemento_tramo_g) según el tipo de entidad GIS recibida y la clave
de sello (sCveSello) que indica el contexto de uso.

Árbol de decisión:
  entidad = splice_closure
    sCveSello = "ET"
      tipo_emp = "DERIVACION"  → ElementoEmpalmeDerivacionG  (stub)
      tipo_emp = otro          → ElementoEmpalmeG
    sCveSello = otro           → ElementoEmpalmeSubterrâneoG  (stub)
  entidad = sheath             → ElementoSeccionG
  entidad = building           → ElementoNodoG

Tras crear el elemento llama .configurarElementos() en todos los casos.

── MÉTODOS TRANSCRITOS ─────────────────────────────────────────────────────────

Magik: c_creador_elemento_tramo_g.new(RsCveSello)
TS:    constructor(cveSello: string)

  Guarda sCveSello. Magik: _self.sCveSello << RsCveSello; _return _clone

────────────────────────────────────────────────────────────────────────────────

Magik: Crea_Elemento_Tramo(RoElemento)
TS:    creaElementoTramo(entidad: EntidadTramo): ElementoTramo

  Discriminación por tipo:
    Magik: RoElemento.is_kind_of?(splice_closure/sheath/building)
    TS:    switch(entidad.entityType)  — discriminated union

  Llama .configurar_elementos() al final en todos los casos.

────────────────────────────────────────────────────────────────────────────────

Magik: crea_elemento_empalme(RoElemento, PsCveSello)
TS:    creaElementoEmpalme(entidad, cveSello): ElementoEmpalmeG

  Si cveSello="ET" y tipo_emp="DERIVACION" → ElementoEmpalmeDerivacionG
  Si cveSello="ET" y otro tipo_emp         → ElementoEmpalmeG
  Si cveSello != "ET"                      → ElementoEmpalmeSubterrâneoG

────────────────────────────────────────────────────────────────────────────────

Magik: crea_elemento_seccion(RoElemento)
TS:    creaElementoSeccion(entidad): ElementoSeccionG

  Wrapper directo: new ElementoSeccionG(entidad).

────────────────────────────────────────────────────────────────────────────────

Magik: crea_elemento_nodo(RoElemento)
TS:    creaElementoNodo(entidad): ElementoNodoG

  Wrapper directo: new ElementoNodoG(entidad).

── PATRÓN is_kind_of?  →  discriminated union ──────────────────────────────────

Magik:  RoElemento.is_kind_of?(splice_closure)
TS:     entidad.entityType === 'splice_closure'

Magik:  RoElemento.is_kind_of?(sheath)
TS:     entidad.entityType === 'sheath'

Magik:  RoElemento.is_kind_of?(building)
TS:     entidad.entityType === 'building'

Cada tipo de entidad extiende la interfaz del elemento correspondiente
añadiendo el campo discriminante entityType.

── STUBS — pendientes de migración ─────────────────────────────────────────────

ElementoEmpalmeDerivacionG   ← c_elemento_empalme_derivacion_g.magik
  Extiende ElementoEmpalmeG. sNombreSimbol='empalme_derivacion'.
  Se instancia cuando sCveSello="ET" y user!_tipo_emp="DERIVACION".

ElementoEmpalmeSubterrâneoG  ← c_elemento_empalme_subterraneo_g.magik
  Extiende ElementoEmpalmeG. sNombreSimbol='empalme_subterraneo'.
  Se instancia cuando sCveSello != "ET" (contexto de planos).

Ambos stubs están declarados en CreadorElementoTramoG.tsx.
Cuando se migren sus ficheros .magik, sustituir las clases stub por los imports.

── LO QUE NO SE TRANSCRIBIÓ ────────────────────────────────────────────────────

- sNombre_grafico: slot declarado pero nunca usado en ningún método visible.
  Mantenido como campo privado #sNombreGrafico con getter/setter.
- Registro de clase en el framework Smallworld.

── DEMO INTERACTIVO ─────────────────────────────────────────────────────────────

El componente React <CreadorElementoTramoGUI /> permite:
  - Cambiar sCveSello entre "ET" y "PL" con un selector.
  - Ver en tiempo real qué clase instancia el factory para cada entityType.
  - Ver la vista SVG del elemento creado en la columna "Vista".

── FLUJO DE USO ────────────────────────────────────────────────────────────────

  const factory = new CreadorElementoTramoG('ET');

  const empalme = factory.creaElementoTramo({
    entityType: 'splice_closure',
    numEmpalme: 42,
    tipoEmp   : 'LINEA',
  });
  // → ElementoEmpalmeG, configurarElementos() ya llamado

  const seccion = factory.creaElementoTramo({
    entityType           : 'sheath',
    calculatedFiberLength: 1523.0,
  });
  // → ElementoSeccionG, configurarElementos() ya llamado

  const nodo = factory.creaElementoTramo({
    entityType: 'building',
    nomNodo   : 'NODO-MAD-01',
    tipo      : 'EDFA-17dBm',
  });
  // → ElementoNodoG, configurarElementos() ya llamado
