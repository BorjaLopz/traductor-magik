DESCRIPCIÓN GENERAL
-------------------
Clase base abstracta para elementos gráficos que representan objetos de
negocio en el Layout Designer de Smallworld (tramos, empalmes, nodos, etc.).

Cada instancia encapsula:
  - Un bounding box (oArea) que define el área que debe cubrir el elemento.
  - Un punto de contacto (oPtoContacto) donde el elemento se ancla al diagrama.
  - Una longitud gráfica (nLongGrafica) que determina la anchura visual.
  - Un contenedor de hijos gráficos (oElementos / c_elementos) con etiquetas
    y símbolos internos.
  - Un mapa de posiciones de etiquetas (collEtiquetas).

La clase NO dibuja por sí sola: define la estructura y la lógica de
posicionamiento. Las subclases concretas implementan los tres métodos
abstractos para crear y ubicar sus elementos internos.


FUNCIONAMIENTO REAL
-------------------
1. Constructor (new / constructor):
   Inicializa todos los slots:
     oElementos    = nuevo ElementosContainer (c_elementos vacío)
     oPtoContacto  = {x:0, y:0}
     collEtiquetas = Map vacío
     bHabilitar    = true
     oEntidad      = objeto de negocio pasado como argumento

2. configurarElementos() [abstracto]:
   La subclase lee oEntidad y configura nLongGrafica, etiquetas, símbolo.

3. creaElementosInternos() [abstracto]:
   La subclase registra los elementos gráficos hijos en oElementos.

4. despliega():
   Paso principal de renderizado:
     a. Calcula el nuevo bbox: oElementos.oArea = reposicionarArea(oArea)
     b. Propaga la ventana:    oElementos.oVentana = oVentana
     c. Posiciona hijos:       dfnUbicacionElementosInternos() [abstracto]
     d. Renderiza:             oElementos.despliega()

5. reposicionarArea(area):
   Pieza central de la geometría:
     altura = area.maxY - area.minY
     nuevo bbox:
       minX = oPtoContacto.x
       minY = oPtoContacto.y - altura/2
       maxX = oPtoContacto.x + nLongGrafica
       maxY = oPtoContacto.y + altura/2
   El elemento queda anclado por su borde izquierdo al punto de contacto
   y centrado verticalmente en torno a él.

6. Gestión de etiquetas:
   asignaValorEtiqueta(key, valor)         → sTexto del hijo
   obtenValorEtiqueta(key)                 → sTexto del hijo
   asignaAlineacionEtiqueta(key, align)    → sAlineacion del hijo
   obtenAlineacionEtiqueta(key)            → sAlineacion del hijo
   setPosEtiqueta(key, posY)               → collEtiquetas[key] = posY
   getPosEtiqueta(key)                     → collEtiquetas[key]

SUBCLASE DEMO (CElementoEntidadDemo)
--------------------------------------
  Entidad: { nombre: string; longitud: number }

  configurarElementos():
    nLongGrafica = entidad.longitud
    Etiqueta_1  = entidad.nombre, alineación center
    Simbolo_1   = "────────────────", alineación center

  creaElementosInternos():
    Registra Etiqueta_1 y Simbolo_1 en oElementos.

  dfnUbicacionElementosInternos():
    Etiqueta_1 → posY = midY + h*0.25  (cuarto superior del bbox)
    Simbolo_1  → posY = midY           (línea central del bbox)


LÓGICA DE reposicionarArea()
-----------------------------
  Entrada: BoundingBox original (oArea).
  Proceso:
    altura = area.maxY - area.minY
    halfH  = altura / 2
    resultado:
      minX = oPtoContacto.x
      minY = oPtoContacto.y - halfH
      maxX = oPtoContacto.x + nLongGrafica
      maxY = oPtoContacto.y + halfH
  Efecto visual: el elemento "sale" hacia la derecha desde el punto de
  contacto, centrado verticalmente. En un diagrama de red cada elemento
  se conecta al siguiente por su borde izquierdo.


UI REACT (ElementoEntidadGUI)
------------------------------
  Controles:
    - Nombre (texto libre)
    - nLong_grafica (número, 20-400)
    - Altura área (número, 10-200)
    - oPtoContacto X, Y (números)
    - bHabilitar (checkbox)
    - Botón "despliega()" → ejecuta el pipeline completo

  Canvas SVG:
    - Línea roja horizontal = oPtoContacto.Y
    - Círculo rojo          = oPtoContacto
    - Rectángulo azul       = BoundingBox repositioned
    - Línea oscura          = símbolo (Simbolo_1) en la mitad del bbox
    - Texto superior        = nombre de la entidad (Etiqueta_1)
    - Cota inferior         = nLong_grafica

  Tabla oElementos:
    Muestra clave / sTexto / sAlineacion / pos_etiqueta de cada hijo.


DEPENDENCIAS
------------

  Geometría 2D pura (unidades de layout, no coordenadas geográficas).
