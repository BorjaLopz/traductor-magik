DESCRIPCIÓN GENERAL
-------------------
Diálogo modal para buscar, previsualizar e insertar símbolos de punto GIS
(point styles) en la página activa del Layout Designer de Smallworld.

En Magik hereda de :model e integra tres widgets Magik: canvas (preview),
tree_item (lista de símbolos) y dos button_item (Insertar / Salir).

En TypeScript se implementa como componente React funcional con un <canvas>
HTML5, una lista scrollable y botones estándar. No requiere OpenLayers ni
Turf.js porque no hay geometría espacial.


FUNCIONAMIENTO REAL DEL COMPONENTE
-----------------------------------
1. Al abrirse (on_activation) refresca la lista de símbolos disponibles.
2. La lista se obtiene llamando a sw_style_system_engine y devuelve nombres
   ordenados de estilos de punto registrados en la vista de estilos GIS
   (sigc_style_view o gis_program_manager.style_view según owner_plugin).
3. Al seleccionar un nombre en la lista:
   - Se dibuja una muestra del símbolo en el canvas de preview usando
     sym.draw_sample() con flip=true, rotate=0.
   - Se almacena el nombre en .sNombreSimbolo.
   - Se publica en el databus: make_data_available(:symbol_name, {...}).
   - Se habilita el botón "Insertar".
4. Al pulsar "Insertar" (ok()):
   - Obtiene la instancia de layout_manager_plugin via la cadena:
       pni_application → layout_plugin → layout_designer → layout_manager_plugin
   - Obtiene el documento activo y la página activa.
   - Calcula el bounds del nuevo símbolo (600×600 unidades):
       · Si no hay símbolos en la página → centro de la página.
       · Si ya hay símbolos → desplaza a la derecha del último (centre.x + width).
   - Crea un symbol_layout con :name, :bounds, :fill_style=unset, :outline_style=unset.
   - Llama LoPagina.add_element(LoSimbolo) y refresca la vista.
5. Al pulsar "Salir" (wm_close):
   - Limpia .sNombreSimbolo = "".
   - Cierra el diálogo.


EQUIVALENCIAS MAGIK → TYPESCRIPT
----------------------------------
  canvas widget (Magik)               →  <canvas> HTML5 + CanvasRenderingContext2D
  tree_item (Magik)                   →  <div> scrollable con onClick por ítem
  button_item :enabled? = false       →  <button disabled={!selectedName}>
  sw_style_system_engine.ordered_symbol_names()  →  array MOCK_SYMBOL_NAMES (16 entradas)
  gis_program_manager.style_view.collection(:sw_gis!gis_point_style)  →  drawSymbolPreview()
  sym.draw_sample(canvas, bounds, ...) →  función drawSymbolPreview() con Canvas API
  bounding_box.new(0,0,600,600)       →  interfaz BoundingBox { minX/minY/maxX/maxY }
  LoPagina.all_elements_of(symbol_layout)  →  estado React pageElements[]
  LoPagina.add_element(LoSimbolo)     →  setPageElements(prev => [...prev, newSymbol])
  layout_view_refresh                 →  re-render React automático
  .owner_plugin.databus.make_data_available  →  prop onInsert callback
  _self.close()                       →  prop onClose callback
  .sNombreSimbolo (slot writable)     →  estado React selectedName


SLOTS PRINCIPALES (Magik) → PROPS/STATE (TypeScript)
------------------------------------------------------
  .sNombreSimbolo   → useState<string | null>(null)  — nombre del símbolo seleccionado
  .ok_button        → lógica disabled del <button>   — habilitado si selectedName != null
  .preview_canvas   → useRef<HTMLCanvasElement>       — referencia al canvas de preview
  .owner_plugin     → prop symbolNames[]             — lista de nombres inyectada desde fuera
  .tree_item        → lista React renderizada        — items del selector visual

LÓGICA DE POSICIONAMIENTO (ok())
---------------------------------
  Primer símbolo:
    bounds.centre = centro de la página (mock: 5000, 5000)
    → minX=4700, minY=4700, maxX=5300, maxY=5300

  Símbolo N (N > 1):
    lastCx = (last.bounds.minX + last.bounds.maxX) / 2
    lastWidth = last.bounds.maxX - last.bounds.minX
    newCx = lastCx + lastWidth   ← desplaza a la derecha del último
    → mismo Y que el anterior


PREVIEW VISUAL (drawSymbolPreview)
------------------------------------
  Dibuja formas SVG-like en Canvas según el nombre del símbolo:
    *CIRCLE / MANHOLE / SPLICE    → círculo relleno
    *SQUARE / JUNCTION            → cuadrado relleno
    *TRIANGLE / TERMINAL          → triángulo relleno
    *DIAMOND / HANDHOLE           → rombo relleno
    *STAR                         → estrella 5 puntas
    *CROSS                        → cruz (dos líneas)
    *ARROW_UP                     → triángulo apuntando arriba
    *ARROW_DOWN                   → triángulo apuntando abajo
    *POLE                         → mástil vertical + travesaño
    (resto)                       → pentágono relleno por defecto
  Siempre añade el nombre del símbolo como etiqueta en la parte inferior.
