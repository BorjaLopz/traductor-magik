── QUÉ HACE ────────────────────────────────────────────────────────────────────

Genera un sello (layout_element) para planos de estudio de conjunto.
El sello muestra los datos de aumento de red secundaria de un distrito
telefónico en una tabla compacta de 5 columnas:

  ┌──────────┬──────────┬──────────┬──────────┬──────────┐
  │  DTO.    │ CONECT.  │ AUMENTO  │ L. PLAZO │  TOTAL   │  ← fila cabecera
  │ NOMBRE   │ (verde)  │  (rojo)  │(naranja) │  (suma)  │  ← fila valores
  └──────────┴──────────┴──────────┴──────────┴──────────┘

Si el distrito posee red directa (es_red_directa? = _true), se añade
una fila previa con la etiqueta "RED DIRECTA" en la celda central (1,3):

  ┌──────────┬──────────┬──────────┬──────────┬──────────┐
  │          │          │RED DIRECT│          │          │  ← fila 1 (red directa)
  │  DTO.    │ CONECT.  │ AUMENTO  │ L. PLAZO │  TOTAL   │  ← fila 2 (cabecera)
  │ NOMBRE   │ (verde)  │  (rojo)  │(naranja) │  (suma)  │  ← fila 3 (valores)
  └──────────┴──────────┴──────────┴──────────┴──────────┘

Dimensiones de la tabla (Magik):
  - 5 columnas × 15 unidades de longitud (oColumnas.elemento(n).nLongitud = 15)
  - 2 ó 3 renglones × 4 unidades (oRenglones.elemento(n).nLongitud = 4)
  - Total tabla: 75u × 8u ó 75u × 12u

── ATRIBUTOS (defined_attributes) ──────────────────────────────────────────────

  1 atributo de layout (:string, :allowed_on_properties_page? = _true):
    :id_distrito   → "Identificador Distrito"  — clave para buscar en GIS
    (default: _unset / null)

  Slots internos (no son defined_attributes en Magik):
    :distrito       → objeto del distrito GIS (rwo con geometría de límite)
    :oCoordOrigen   → coordenada de inicio del sello en el plano
    :oWindow        → ventana/canvas donde se desplegará (draw_content_on)
    :oTablas        → gestor de tablas del layout_element

Magik: c_sello_aumentos_secundarios.Inicializa(_optional RoCoord)
TS:    inicializa(coord)  +  async inicializaConGis(coord, service)

  La versión base (inicializa) sólo fija fillColor y origen (sin GIS).
  La versión async (inicializaConGis) reproduce la lógica completa de Magik:

  Magik:
    _self.set_fill_colour(colour.called("white"))
    _if RoCoord _is _unset _then RoCoord << coordinate.new(0,0) _endif
    _self.oCoordOrigen << RoCoord
    _self.oTablas << c_tablas.new(_self)

    _if _self.id_distrito _isnt _unset
      reg_distrito << dataset.collections[:user!_distrito].at(id)
      .distrito    << reg_distrito.user!_limite
      red_directa? << .distrito.rwo.es_red_directa?
    _else
      _self.id_distrito << .distrito.rwo.id
      red_directa?      << .distrito.rwo.es_red_directa?
    _endif

    _self.crea_sello_secundario(RoCoord, red_directa?)
    LoArea << _self.oTablas.area_total()
    _self.bounds << LoArea
    _self.llena_Celdas(red_directa?)

  TS (equivalencia):
    - gis_program_manager.cached_dataset(:landbase) → IMockGisDistritoService
    - .collections[:user!_distrito].at(id)          → service.fetchDistrito(id)
    - .distrito.rwo.es_red_directa?                 → distrito.esRedDirecta
    - _self.oTablas.area_total()                    → getBounds()

Magik: c_sello_aumentos_secundarios.llena_celdas(red_directa?)
TS:    llenarCeldas(redDirecta)

  Rellena las celdas de :tbl_aumento con textos y colores.

  Estructura condicional:
    _if red_directa?
      Celda(1,3) = "RED DIRECTA" (ntamanio=30)
      fila_tit=2 / fila_valor=3
    _else
      fila_tit=1 / fila_valor=2
    _endif

  Cabecera (ntamanio=20):
    Celda(fila_tit, 1) = "DTO."
    Celda(fila_tit, 2) = "CONECT."
    Celda(fila_tit, 3) = "AUMENTO"
    Celda(fila_tit, 4) = "L. PLAZO"
    Celda(fila_tit, 5) = "TOTAL"

  Valores (ntamanio=30):
    Celda(fila_valor, 1) = NomDistrito     = .distrito.rwo.user!_distrito.write_string
                                             TS: distrito.nombre
    Celda(fila_valor, 2) = ParExist        = resp[:existente]     .scolor="green"
    Celda(fila_valor, 3) = ParProy         = resp[:proyectado]    .scolor="red"
    Celda(fila_valor, 4) = ParLP           = resp[:largo_plazo]   .scolor="orange"
    Celda(fila_valor, 5) = ParTotal        = proy + exist + LP    (sin color)

  Fuente de datos:
    Magik: resp << .distrito.rwo.obtener_numero_pares()
    TS:    resp =  distrito.obtenerPares() → NumeroPares { existente, proyectado, largoPlazo }

Magik: c_sello_aumentos_secundarios.draw_content_on(window)
TS:    drawContentOn()

  Magik:
    _self.oWindow << window
    _self.oTablas.Despliega(window)

  TS:
    Devuelve { tablas, celdas } para que el componente React los renderice
    como un SVG. No hay canvas real: el componente SelloAumentosSecundariosUI
    actúa como sustituto de oTablas.Despliega(window).

── FLUJO DE USO COMPLETO ────────────────────────────────────────────────────────

  // 1. Crear instancia (post_initialisation → inicializa(0,0))
  const sello = new SelloAumentosSecundarios();

  // 2. Asignar id del distrito (equivale a definir el layout attribute)
  sello.idDistrito = 'D-01';

  // 3. Inicializar con GIS — carga distrito, crea tabla, llena celdas
  await sello.inicializaConGis({ x: 0, y: 0 }, mockGisDistritoService);
  // sello.distrito = { id:'D-01', nombre:'NORTE', esRedDirecta:true, ... }
  // → tablas.get('tbl_aumento') creada con 3 filas (red directa)
  // → celdas['1-3'] = 'RED DIRECTA'
  // → celdas['2-1'..'2-5'] = cabeceras
  // → celdas['3-1'..'3-5'] = valores (colores: verde/rojo/naranja)

  // 4. Renderizado (equivale a draw_content_on)
  const { tablas, celdas } = sello.drawContentOn();

  // 5. Obtener dimensiones del sello (equivale a oTablas.area_total())
  const bounds = sello.getBounds();
  // bounds = { width: 75, height: 12 }  (mm)

── DEMO INTERACTIVO ─────────────────────────────────────────────────────────────

  <SelloAumentosSecundariosUI /> muestra:

  - Selector de distrito (D-01 a D-04) con indicación de red directa
  - Botón "Inicializa()" que llama a inicializaConGis() con 250ms de latencia mock
  - SVG del sello generado (escala 7px/mm):
      · 2 filas (no red directa): cabecera azul claro + valores en blanco
      · 3 filas (red directa):    fila 1 rosa "RED DIRECTA" + cabecera + valores
      · Colores de texto: verde (existente) / rojo (proyectado) / naranja (largo plazo)
  - Tabla de propiedades con campo Magik, descripción, valor y color de texto
  - Leyenda de dimensiones de la tabla generada
