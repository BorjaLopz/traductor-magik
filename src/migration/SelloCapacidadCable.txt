── QUÉ HACE ────────────────────────────────────────────────────────────────────

Cuadro de capacidad de cable para planos de red de fibra óptica.
Se imprime como "sello" (bloque de anotación) con dos secciones apiladas:

  1. Título: 2 filas — "CUADRO" / "PARA CAPACIDAD DE CABLE" en verde
  2. Contenido: 18 filas × 2 columnas — código letra → capacidad (pares/tipo)

El sello tabula los 18 tipos de cable reconocidos, desde "A = 10 PS." hasta
"Z = FIBRAS OPTICAS", permitiendo identificar de un vistazo la capacidad de
cualquier cable referenciado en el plano.

── MÉTODOS TRANSCRITOS ─────────────────────────────────────────────────────────

    Origen: oCoordInicio

  tbl_contenido:
    Dimensiones: :ren={6×18}, :col={44} → 18 filas × 6u = 108u alto × 44u ancho
    Columnas internas: col1=7u (código), col2=37u (descripción)
    Origen: (oCoordInicio.x, oCoordInicio.y + 12u) — justo debajo del título

  LfDesplazaY: longitud_total_renglones({:tbl_titulo}) = 12u
  Sin bug: una sola llamada (a diferencia de SelloSimbologiaDiagramaEmpalmes).

── OVERRIDE NECESARIO ──────────────────────────────────────────────────────────

  CBaseSelloFibra.asignarTextoCelda() solo guarda el ÚLTIMO texto por tabla,
  ignorando (fila, col). SelloCapacidadCable lo sobreescribe para almacenar
  texto por clave "fila-col" en un Map<CellKey, CeldaTexto> por tabla.

  Tipo CellKey = `${number}-${number}` — identifica inequívocamente cada celda.

── LO QUE NO SE TRANSCRIBIÓ ────────────────────────────────────────────────────

  - Clase completa c_base_sello_fibra (solo stub mínimo reutilizado de [13]).
  - Integración con el sistema de ventanas/planos de Smallworld.
  - Lógica de oculta_bordes_celdas para :borde_der_izq en fila 1 del título:
    en el SVG se omite la línea superior/lateral de esa celda específica, pero
    la gestión dinámica de bordes del sistema Magik no se modela completamente.

── FLUJO DE USO ────────────────────────────────────────────────────────────────

  const sello = new SelloCapacidadCable();
  sello.oCoordInicio = { x: 0, y: 0 };
  sello.configurarTabla();    // crea tbl_titulo (2×1) + tbl_contenido (18×2)
  sello.etiquetarCeldas();    // asigna texto verde a todas las celdas

  // Acceder a celdas individuales:
  const celda = sello.getCelda('tbl_contenido', 1, 1); // → { texto: 'A', ... }
  const titulo = sello.getCelda('tbl_titulo', 2, 1);   // → { texto: 'PARA CAPACIDAD DE CABLE', ... }
