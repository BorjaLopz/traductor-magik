── QUÉ HACE ────────────────────────────────────────────────────────────────────

Implementa el patrón Factory para la creación de sellos de plano en PNI.

Un "sello" en este contexto es el bloque de información que aparece en el
recuadro de un plano técnico GIS (equivalente al cartucho o leyenda de un
plano cartográfico). Cada tipo de plano necesita un sello diferente con campos
y formatos distintos.

La clase recibe dos datos de entrada:
  - RsNomSello  → nombre/identificador del tipo de sello deseado (string)
  - RoBounding  → bounding box que define el área donde se dibujará el sello

Y devuelve la instancia correcta sin que el código llamador necesite conocer
qué subclase concreta se crea.

Casos posibles (según la lógica _if/_elif/_else del Magik original):
  "CONSTRUCCION"       → instancia de c_sello_estandar_construccion
  "DIAGRAMA_EMPALMES"  → instancia de c_sello_estandar_diag_empal
  cualquier otro valor → instancia de c_sello_estandar_ctl_edo
                         (nota: 06/05/05 DSB — renombrado de ctl_localidad
                          a ctl_edo para reflejar el campo estado, no localidad)

────────────────────────────────────────────────────────────────────────────────

── PATRÓN DE DISEÑO ────────────────────────────────────────────────────────────

Magik: condicional _if/_elif/_else manual → instanciación directa con .new_with
TS:    switch discriminado sobre nomSello → new SelloXxx(bounds)

  El patrón Factory es idéntico en ambos lados: el llamador pasa un identificador
  de tipo (string) y recibe un objeto listo para usar, sin saber qué clase
  concreta se instanció. En TS se refuerza con el tipo abstracto SelloBase que
  garantiza que cualquier sello expone al menos { tipo, bounds }.

────────────────────────────────────────────────────────────────────────────────

── MÉTODO TRANSCRITO ───────────────────────────────────────────────────────────

Magik: c_sello_estandar.crea_sello(RsNomSello, RoBounding)
TS:    CSelloEstandar.creaSello(nomSello, bounds): SelloBase
       creaSello(nomSello, bounds): SelloBase  [función pura exportada]

  Magik original:
    _if RsNomSello = "CONSTRUCCION"
      LoSello << c_sello_estandar_construccion.new_with(:bounds, RoBounding)
    _elif RsNomSello = "DIAGRAMA_EMPALMES"
      LoSello << c_sello_estandar_diag_empal.new_with(:bounds, RoBounding)
    _else
      LoSello << c_sello_estandar_ctl_edo.new_with(:bounds, RoBounding)
    _endif
    _return LoSello

  TypeScript:
    switch (nomSello) {
      case 'CONSTRUCCION':      return new SelloEstandarConstruccion(bounds);
      case 'DIAGRAMA_EMPALMES': return new SelloEstandarDiagEmpal(bounds);
      default:                  return new SelloEstandarCtlEdo(bounds);
    }

  La lógica es directa: la cadena de _if/_elif Magik se convierte en switch/case
  TS. El _else de Magik se mapea al default del switch.

── STUBS DE SUBCLASES ──────────────────────────────────────────────────────────

  Las tres subclases referenciadas en crea_sello aún no han sido migradas de
  forma completa. Se definen como stubs tipados que extienden SelloBase:

  SelloEstandarConstruccion  ← c_sello_estandar_construccion  (pendiente)
  SelloEstandarDiagEmpal     ← c_sello_estandar_diag_empal    (pendiente)
  SelloEstandarCtlEdo        ← c_sello_estandar_ctl_edo       (pendiente)

  Cada stub almacena únicamente el campo `bounds` (BoundingBox) heredado de
  SelloBase. Cuando se migren individualmente, se añadirán los campos específicos
  de cada tipo de sello (cabecera, fecha, número de plano, etc.).

── CONSTANTE SHARED ────────────────────────────────────────────────────────────

  Magik: c_sello_estandar.define_shared_constant(:allowed_on_menu?, _false, :public)
  → Metadato del framework Smallworld. Indica que esta clase no aparece en menús
    de usuario. Sin equivalente React/TS — no transcrito.

── LO QUE NO SE TRANSCRIBIÓ ────────────────────────────────────────────────────

- def_slotted_exemplar(:c_sello_estandar, {})
  → Declaración de la clase en Smallworld sin slots propios.
    En TS la clase CSelloEstandar no tiene estado de instancia (stateless factory).

- define_shared_constant(:allowed_on_menu?, _false, :public)
  → Metadato de visibilidad en el framework PNI. Sin equivalente en React.

- El método crea_sello no llama a .inicializa() — eliminiado en 17/01/2005
  según el historial de revisiones. No aplica.

── FLUJO DE USO ────────────────────────────────────────────────────────────────

  // Vía clase:
  const factory = new CSelloEstandar();
  const sello = factory.creaSello('CONSTRUCCION', { xmin:0, ymin:0, xmax:500, ymax:300 });
  console.log(sello.tipo);   // → 'CONSTRUCCION'
  console.log(sello.bounds); // → { xmin:0, ymin:0, xmax:500, ymax:300 }

  // Vía función pura (atajo):
  const sello = creaSello('DIAGRAMA_EMPALMES', bounds);

  // Componente demo React:
  <SelloEstandarUI />
  // → Selector de RsNomSello + inputs BoundingBox + botón crea_sello()
  //   Muestra clase instanciada, tipo y bounds, + equivalencia Magik
