── QUÉ HACE ────────────────────────────────────────────────────────────────────

Es el sello base de planos de red de cobre. Define la estructura y los datos
comunes a todos los sellos estándar derivados (título, compañía, fechas, escala).

Genera 4 tablas apiladas horizontalmente que forman la franja inferior del plano:

  ┌──────────────────────────────────────────────────────────────────────────────┐
  │                    ┌──────────────┬─────────┬──────────┐                    │
  │                    │ RED NACIONAL │ FECHA   │          │                    │
  │  [NOMBRE DE        │  LTIMA MILLA │ DIBUJO  │  ESCALA  │                    │
  │   PLANO / UBIC.    │ S.A.P.I.C.V.│ REVISO  │  1:2000  │                    │
  │   (rotado 90°)]    └──────────────┴─────────┴──────────┘                    │
  └──────────────────────────────────────────────────────────────────────────────┘
     tbl_ubicacion      tbl_compania  tbl_FecDibRev  tbl_escala
     (15mm × 274mm)     (25mm × 15mm) (35mm × 15mm) (15mm × 15mm)

  Las tres tablas derechas (compañía, FecDibRev, escala) se alinean en la parte
  inferior de tbl_ubicacion con un offset vertical calculado como:
    Y = -(altura_ubicacion - 150) = -(274 - 150) = -124 mm

  No hay cálculos espaciales (no Turf.js) ni interacción con el mapa (no OL).

── TIPOS CLAVE INTRODUCIDOS ────────────────────────────────────────────────────

── LO QUE NO SE TRANSCRIBIÓ ────────────────────────────────────────────────────

- _pragma(classify_level=advanced, topic={plotting}, usage={subclassable})
  → Metadatos Smallworld. Sin equivalente TS.

- c_base_sello_cobre (clase padre)
  → Solo se usa a través de la interfaz de servicio. Los métodos del padre
    (_self.tipo_plano(), _self.escala(), _self.nombre_plano()) se abstraen
    en SelloEstandarBaseService para no requerir la cadena de herencia completa.

- swg_dsn_admin_engine.active_scheme / active_design
  → Singleton de Smallworld que da acceso al proyecto activo y al design.
    En TS: service.esProyectoFalc() / service.obtenerTipoPlano().
    LoEtapa y LoFase (leídos de active_design) están en el código comentado
    del original (##) → no se transcriben.

- .o_tablas / .o_coord_inicio / coordinate.new(x,y)
  → Motor de layout del Layout Designer de Smallworld.
    En TS: configurarTabla() devuelve los valores numéricos equivalentes;
    el componente React los convierte a posiciones CSS absolutas.

- asigna_medidas_tabla(lo_tabla, pl_xxx)
  → Helper de la clase base que aplica filas y columnas de un property_list
    a una tabla del Layout Designer. En TS se inlinan directamente en TableDef.

- .oCeldas.Celda(1,1).oElemento.nGrados << 90
  → Rotación nativa del Layout Designer. En TS: CSS writingMode vertical-rl.

- Renglón de escala comentado con ##:
  ## + " / " + LoEtapa + " /  " + LoFase
  → Código comentado en el original (etapa y fase no se incluían). No se transcribe.
