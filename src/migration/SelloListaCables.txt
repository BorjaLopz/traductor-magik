── QUÉ HACE ────────────────────────────────────────────────────────────────────

Es un sello de plano imprimible que muestra la lista de cables de fibra óptica
asociados a un Distrito Óptico. Genera tres tablas apiladas verticalmente:

  ┌──────────────────────────────────────────────────────────────┐
  │  CANTIDAD DE CABLE A PROYECTAR          (100 mm × 20 mm)     │  ← tbl_titulo
  ├──────────────────┬──────────────────┬───────────────────────┤
  │   CAPACIDAD      │   TIPO DE CABLE  │   LONGITUD (MTS.)     │  ← tbl_subtitulos
  ├──────────────────┼──────────────────┼───────────────────────┤  (20 mm altura)
  │   FOE-24         │   Fibra Óptica   │   1250.5              │
  │   FOE-12         │   Fibra Óptica   │   825.3               │  ← tbl_contenido
  │   CU-2           │   Cobre          │   500.0               │  (10 mm/renglón)
  └──────────────────┴──────────────────┴───────────────────────┘

  Anchos de columna: 33 mm | 33 mm | 34 mm  (total 100 mm)
  Renglones de contenido: max(1, cables.length)

Contexto técnico:
  En Smallworld GIS, un "sello de plano" es un objeto gráfico insertado en el
  Layout Designer que se pinta en el documento imprimible. Este sello en concreto
  lista los cables secundarios agrupados de un Distrito Óptico (entidad de red)
  y sirve como referencia tabular en planos de construcción de fibra óptica.

── LO QUE NO SE TRANSCRIBIÓ ────────────────────────────────────────────────────

- _pragma(classify_level=advanced/restricted, topic={plotting}, usage={subclassable/redefinable})
  → Metadatos de clasificación del Layout Designer de Smallworld. Sin equivalente TS.

- c_sello_lista_cables.define_attributes()  (llamada al final del .magik)
  → Registro de atributos en el runtime Smallworld. En TS se llama implícitamente
    mediante la propiedad estática definedAttributes().

- :allowed_on_properties_page? _false / :editor _unset
  → Opciones de visualización del panel de propiedades del Layout Designer SW.
    No tienen equivalente en una aplicación React/TypeScript.

- rope.new() / fast_elements()
  → Estructuras de datos propias de Smallworld (rope = lista enlazada mutable).
    Sustituidas por Array<CableData> estándar de TypeScript.

- _global dato
  → Variable global de Magik con ámbito de módulo. En TS se convierte en valor
    de retorno de llenaDatatosCeldas() para evitar estado global.

- c_base_sello_fibra (herencia completa)
  → Solo se transcribe la parte visible desde c_sello_lista_cables. La cadena
    de herencia completa de Smallworld (c_base_sello → c_sello → etc.) se
    abstrae en CBaseSelloFibraLayout (TablaEncGeoreferencia.tsx).
