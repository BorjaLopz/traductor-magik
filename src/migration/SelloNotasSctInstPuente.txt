── QUÉ HACE ────────────────────────────────────────────────────────────────────

Sello de notas SCT (Secretaría de Comunicaciones y Transportes) para planos de
instalación lateral de cable en puente. Se compone de:
  1. Tabla 2×1 (tbl_notas_grales):
       fila 1 (10mm)  — franja de título
       fila 2 (170mm) — área de notas
       col 1  (165mm) — ancho del sello
  2. Texto de notas 1-11:
       notas 1-4 heredadas de c_sello_notas_sct (_super)
       notas 5-11 propias de instalación lateral en puente

── SLOTS ────────────────────────────────────────────────────────────────────────

  sTipoCable  string  → Magik: .s_tipo_cable
    Tipo de cable (p.ej. "FIBRA ÓPTICA", "CABLE DE COBRE").
    Interpolado en notas 5, 6 y 7.

  sEstado     string  → Magik: .s_estado
    Entidad federativa (p.ej. "JALISCO").
    Interpolado en notas 5 y 9.

  oTablas     GestorTablas
    Modelo del sistema de tablas Magik (oTablas).
    Ver sección GESTOR DE TABLAS más abajo.

── GESTOR DE TABLAS ─────────────────────────────────────────────────────────────

  GestorTablas modela el slot .oTablas de Magik.
  Mantiene Map<id, TablaNota>.

  crearTabla(nFilas, nCols, id)     → TablaNota con celdas pre-pobladas en Map
  elemento(id)                      → TablaNota | undefined
  celda(tablaId, fila, col)         → CeldaNota | undefined  (key: "fila,col")

  TablaNota:
    id        : string
    renglones : RenglonLayout[]   (index 0-based, Magik elemento(N) es 1-based)
    columnas  : ColumnaLayout[]
    celdas    : Map<string, CeldaNota>
    origen    : Coordenada

  CeldaNota:
    sTexto: string    → Magik: oCeldas.Celda(f,c).oElemento.sTexto
