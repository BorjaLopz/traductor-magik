── QUÉ HACE ────────────────────────────────────────────────────────────────────

Sello de notas SCT para planos de instalación marginal subterránea de cable
en carretera (derecho de vía). Se compone de:
  1. Tabla 2×1 (tbl_notas_grales):
       fila 1 (10mm)  — franja de título
       fila 2 (265mm) — área de notas  ← más alta que inst_puente (170mm)
       col 1  (170mm) — ancho del sello ← más ancho que inst_puente (165mm)
  2. Texto de notas 1-15:
       notas 1-4 heredadas de c_sello_notas_sct (_super)
       notas 5-15 propias de instalación marginal subterránea

── NUEVO SLOT RESPECTO AL PADRE ─────────────────────────────────────────────────

  sInstalacion  string  → Magik: .s_instalacion
    Tipo de instalación marginal (p.ej. "SUBTERRÁNEA", "AÉREA").
    Interpolado en notas 5, 6, 7, 14 y 15.

  (sTipoCable y sEstado heredados de SelloNotasSct)

── DIFERENCIAS DE LAYOUT vs c_sello_notas_sct_inst_puente ───────────────────────

  Dimensión       inst_puente     marg_sub
  ─────────────────────────────────────────
  renglón 1       10mm            10mm   (igual)
  renglón 2       170mm           265mm  ← más espacio para notas 5-15
  columna 1       165mm           170mm  ← 5mm más ancho

────────────────────────────────────────────────────────────────────────────────

Magik: c_sello_notas_sct_marg_sub.prvAsignaTexto()
TS:    prvAsignarTexto(): void

  1. Llama super.prvAsignarTexto() — agrega notas 1-4 del padre
  2. Construye texto notas 5-15 interpolando:
       ${sInstalacion} — tipo de instalación marginal
       ${sTipoCable}   — tipo de cable
       ${sEstado}      — entidad federativa
  3. Magik: oTablas.elemento(:tbl_notas_grales).oCeldas.Celda(2,1).oElemento.sTexto +<< LsTexto
     TS:    celda('tbl_notas_grales', 2, 1).sTexto += texto

  Notas propias (5-15):
     5 — Verificación de ubicación en campo por RGCC en ${sEstado}
         (instalación ${sInstalacion} con cable ${sTipoCable})
     6 — Instalación conforme indicaciones RGCC e inspecciones en campo
     7 — Franja paralela eje camino, ancho máx. 2.50m desde límite derecho de vía
     8 — Profundidad mínima 1.20m (1.50m desde fondo de cunetas)
     9 — Cunetas afectadas: reconstruir y zampear, restituir filtro
    10 — Relleno de excavación dejando terreno en condiciones originales
    11 — Daños a pavimento/acotamiento/cuneta: reparar inmediato por cuenta TELMEX
    12 — Señalización SCT Manual 1986; señalamiento luminoso nocturno permanente
    13 — Retirar materiales sobrantes del derecho de vía al terminar obra
    14 — Cruzamientos subterráneos derivados de esta instalación: solicitar por separado
    15 — Instalaciones laterales en puentes/alcantarillas del trayecto: solicitar por separado

  Flujo completo:
    generar(coord): inicializarTabla(coord) + prvAsignarTexto()

── FLUJO DE USO ────────────────────────────────────────────────────────────────

  const sello = new SelloNotasSctMargSub();
  sello.sInstalacion = 'SUBTERRÁNEA';
  sello.sTipoCable   = 'FIBRA ÓPTICA';
  sello.sEstado      = 'JALISCO';
  sello.generar({ x: 0, y: 0 });      // crea tabla + asigna notas 1-15

  // Tabla:
  const tbl = sello.getTablaNota();
  // tbl.renglones[0].longitud  === 10
  // tbl.renglones[1].longitud  === 265
  // tbl.columnas[0].longitud   === 170
  // tbl.origen                 === { x: 0, y: 0 }

  // Texto:
  const texto = sello.getTextoNotas();
  // notas 1-4 (super) + notas 5-15 con "SUBTERRÁNEA", "FIBRA ÓPTICA", "JALISCO"
