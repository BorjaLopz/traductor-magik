── QUÉ HACE ────────────────────────────────────────────────────────────────────

Cuadro de simbología para planos de diagramas de empalmes de fibra óptica.
Se imprime en el plano como un "sello" (bloque de anotación) con dos secciones:
  1. Título: franja con texto "SIMBOLOGIA" en verde oscuro
  2. Contenido: área con el símbolo gráfico del diagrama (leyenda de empalmes)

── MÉTODOS TRANSCRITOS ─────────────────────────────────────────────────────────

Magik: c_sello_simbologia_diagrama_empalmes.configura_tabla()
TS:    configurarTabla(): void

  Crea dos tablas de layout:

  tbl_titulo:
    Dimensiones: :ren={8}, :col={65}  → 8 renglones × 65 columnas
    Origen: oCoordInicio (herencia)

  tbl_contenido:
    Dimensiones: :ren={110}, :col={65} → 110 renglones × 65 columnas
    Origen: (oCoordInicio.x, oCoordInicio.y - LfDesplazaY)
      donde LfDesplazaY = 2 × longitud_total_renglones({:tbl_titulo})

  BUG PRESERVADO:
    Magik calcula LfDesplazaY en dos líneas que referencian :tbl_titulo dos veces:
      LfDesplazaY = longitud_total_renglones({:tbl_titulo})
      LfDesplazaY = LfDesplazaY + longitud_total_renglones({:tbl_titulo})  ← :tbl_titulo × 2
    Resultado: desplazaY = 2 × altura_tbl_titulo
    Efecto visual: hueco entre título y contenido = 1 × altura_titulo
    Lo correcto debería ser: tbl_titulo + tbl_contenido (para que no haya hueco)

────────────────────────────────────────────────────────────────────────────────

Magik: c_sello_simbologia_diagrama_empalmes.etiqueta_celdas()
TS:    etiquetarCeldas(): void

  tbl_titulo, celda [1,1]:
    Magik: asigna_texto_celda(:tbl_titulo, 1, 1, "SIMBOLOGIA",
               30, :centre_centre, 0, {0.0, 0.2993, 0.0})
    TS:    texto="SIMBOLOGIA", tamanio=30, alineacion='centre_centre',
           rotacion=0, color=[0.0, 0.2993, 0.0]
    Color: {R:0.0, G:0.2993, B:0.0} → rgb(0, 76, 0) — verde oscuro

  tbl_contenido, celda [1,1]:
    Magik: asigna_simbolo_celda(:tbl_contenido, 1, 1, "simbologia_diagrama_emp", 3)
    TS:    simbolo.nombre='simbologia_diagrama_emp', simbolo.tamanio=3
    Nota: "simbologia_diagrama_emp" es un recurso gráfico del sistema Smallworld.
    En TypeScript se representa como SVG inline con la leyenda típica del diagrama.

── SISTEMA DE TABLAS — c_base_sello_fibra ──────────────────────────────────────

  El stub de CBaseSelloFibra modela:
    oCoordInicio          → coordenada de origen del sello
    tablas: Map<string>   → registro de TablaLayout por id
    crearTabla()          → registra nueva tabla
    longitudTotalRenglones(ids[]) → suma de renglones de las tablas indicadas
    asignarMedidasTabla() → asigna renglones/columnas
    asignarTextoCelda()   → asigna texto+estilo a celda
    asignarSimboloCelda() → asigna símbolo gráfico a celda

── SÍMBOLO "simbologia_diagrama_emp" ────────────────────────────────────────────

  En Smallworld: recurso gráfico del sistema que muestra la leyenda del
  diagrama de empalmes (tipos de fibra, tipos de empalme, etc.).

  En TypeScript: SVG inline representativo con 6 entradas de leyenda:
    - Empalme de cobre:       línea + rombo hueco
    - Empalme derivación:     línea + rombo relleno + rama inferior
    - Empalme subterráneo:    línea discontinua + círculo
    - Fibra activa:           línea continua azul
    - Fibra de reserva:       línea discontinua azul
    - Fibra cortada:          línea + marca ×

── DEMO INTERACTIVO ─────────────────────────────────────────────────────────────

── FLUJO DE USO ────────────────────────────────────────────────────────────────

  const sello = new SelloSimbologiaDiagramaEmpalmes();
  sello.oCoordInicio = { x: 0, y: 0 };
  sello.configurarTabla();   // crea tbl_titulo + tbl_contenido
  sello.etiquetarCeldas();   // asigna texto y símbolo

  // Acceder a las tablas resultantes:
  const titulo    = sello.getTablaTitulo();
  const contenido = sello.getTablaCOntenido();

  // titulo.origen   = { x: 0, y: 0 }     (igual que oCoordInicio)
  // contenido.origen = { x: 0, y: 16 }   (2 × 8 renglones de tbl_titulo)
  // titulo.texto.color = [0.0, 0.2993, 0.0] → "rgb(0, 76, 0)"
