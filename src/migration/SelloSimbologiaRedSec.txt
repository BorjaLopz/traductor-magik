── QUÉ HACE ────────────────────────────────────────────────────────────────────

Cuadro de simbología para planos de red secundaria de fibra óptica.
Se imprime en el plano como un "sello" (bloque de anotación) con tres secciones:
  1. Título:    franja con texto "SIMBOLOGIA DE LA RED SECUNDARIA" en verde oscuro
  2. Cabecera:  fila con 3 columnas (DESCRIPCION | RED EXISTENTE | RED PROYECTADA)
  3. Contenido: área con el símbolo gráfico de la red secundaria

── MÉTODOS TRANSCRITOS ─────────────────────────────────────────────────────────

Magik: c_sello_simbologia_red_sec.configura_tabla()
TS:    configurarTabla(): void

  Crea tres tablas de layout:

  tbl_titulo:
    Dimensiones: :ren={8}, :col={130}  → 8 renglones × 130 columnas
    Origen: oCoordInicio (herencia)

  tbl_titulo2:
    Dimensiones: :ren={8}, :col={60,35,35}  → 8 renglones × 3 columnas (total 130)
    Origen: (oCoordInicio.x, oCoordInicio.y + LfDesplazaY)
    donde LfDesplazaY = longitudTotalRenglones(['tbl_titulo']) = 8

  tbl_contenido:
    Dimensiones: :ren={110}, :col={130}  → 110 renglones × 130 columnas
    Origen: (oCoordInicio.x, oCoordInicio.y + LfDesplazaY)
    donde LfDesplazaY = 8 + longitudTotalRenglones(['tbl_titulo2']) = 16

  NOTA: La acumulación de LfDesplazaY es CORRECTA (tbl_titulo + tbl_titulo2 = 16).
  No hay bug de duplicado como en c_sello_simbologia_diagrama_empalmes.

── OVERRIDE asignarTextoCelda — PROBLEMA DEL STUB BASE ─────────────────────────

  El stub CBaseSelloFibra.asignarTextoCelda() ignora los parámetros fila/col
  y almacena un único CeldaTexto por tabla (TablaLayout.texto?).

  tbl_titulo2 tiene 3 celdas independientes (columnas 1, 2, 3).
  Si se usara la implementación base, cada llamada sobreescribiría la anterior
  y solo quedaría "RED PROYECTADA" (la última).

  Solución: SelloSimbologiaRedSec.asignarTextoCelda() override intercepta
  las llamadas con tablaId === 'tbl_titulo2' y las guarda en:
    private celdas2: Map<number, CeldaTexto>   (key = col, 1-based)

  Las llamadas para otras tablas se delegan con super.asignarTextoCelda().

  API de acceso:
    getCeldasTitulo2(): Map<number, CeldaTexto>

── SÍMBOLO "simbologia_de_la_red_sec" ───────────────────────────────────────────

  En Smallworld: recurso gráfico del sistema con leyenda de la red secundaria.

  En TypeScript: SVG inline representativo con estructura 3 columnas (col1=descripción,
  col2=red existente, col3=red proyectada) y 6 filas de elementos:
    - CABLE SUBTERRÁNEO FO:   línea azul oscuro / línea azul discontinua
    - CABLE AÉREO FO:         línea naranja + círculos / ídem discontinua
    - CONDUCTO PVC:           línea cyan gruesa / ídem discontinua
    - CÁMARA DE EMPALME:      cuadrado (outline) sólido / discontinuo
    - EMPALME FO:             diamante sólido / discontinuo
    - NODO / ODF:             círculo sólido / discontinuo

── FLUJO DE USO ────────────────────────────────────────────────────────────────

  const sello = new SelloSimbologiaRedSec();
  sello.oCoordInicio = { x: 0, y: 0 };
  sello.configurarTabla();    // crea tbl_titulo + tbl_titulo2 + tbl_contenido
  sello.etiquetarCeldas();    // asigna textos (4 celdas) + símbolo

  // Acceder a las tablas:
  const titulo    = sello.getTablaTitulo();
  const titulo2   = sello.getTablaTitulo2();
  const contenido = sello.getTablaContenido();
  const celdas2   = sello.getCeldasTitulo2();

  // titulo.origen    = { x: 0, y: 0  }  (igual que oCoordInicio)
  // titulo2.origen   = { x: 0, y: 8  }  (tbl_titulo height)
  // contenido.origen = { x: 0, y: 16 }  (tbl_titulo + tbl_titulo2)
  // celdas2.get(1).texto = "DESCRIPCION"
  // celdas2.get(2).texto = "RED EXISTENTE"
  // celdas2.get(3).texto = "RED PROYECTADA"
