── QUÉ HACE ────────────────────────────────────────────────────────────────────

Es un servicio singleton que adapta los estilos visuales de texto de objetos GIS
según su estado de construcción. Funciona como una capa de transformación de
estilos entre el modelo de datos de la red (estado de un cable/elemento) y el
motor de renderizado del Layout Designer de Smallworld.

El único método con lógica activa en el Magik original es:
  obtener_estilo_blanco_y_negro_txt(PoRwo_est, Pc_construccion?)

El segundo método (línea) está completamente vacío en el original (stub).

No hay cálculos espaciales ni interacción con mapa →
no se usa Turf.js ni OpenLayers.

  La unión de tipos AnyStyleInput = GisTextStyle | RwoStyle | {className?: string}
  modela los tres ramos. El else branch devuelve la entrada tal cual, igual que
  en el Magik original.

PASO 2 — Cálculo de propiedades según Pc_construccion

  Pc_construccion   Magik                              TypeScript
  ────────────────  ────────────────────────────────── ──────────────────────────
  "PROYECTADO"      font.new_logical("bold")           loFont  = 'bold'
                    colour.called(:red)                loColor = COLOURS.red
                    xscale + (xscale*0.10).truncated   loEscalaX = xscale + Math.trunc(xscale*0.10)
                    yscale + (xscale*0.10).truncated   loEscalaY = yscale + Math.trunc(xscale*0.10)

  _unset (omitido)  font.new_logical("plain")          loFont  = 'plain'
                    colour.called(:black)              loColor = COLOURS.black
                    escala sin cambio                  loEscalaX = loEstilo.xscale  (sin cambio)

  otro valor        font.new_logical("plain")          loFont  = 'plain'
                    colour.called(:green)              loColor = COLOURS.green
                    escala sin cambio                  loEscalaX = loEstilo.xscale  (sin cambio)

  OBSERVACIÓN IMPORTANTE:
    En el Magik original, el cálculo del incremento de yscale usa LoEstilo.xscale
    (no yscale). Esto parece un copy-paste del autor (dvalenci), pero es el
    comportamiento real del sistema. La migración TS lo replica exactamente:
      loEscalaY = loEstilo.yscale + Math.trunc(loEstilo.xscale * 0.10)

  .truncated en Magik ≡ Math.trunc() en TypeScript:
    Ambos truncan el decimal hacia cero sin redondear.
    Ejemplo: (20 * 0.10).truncated = 2 → loEscalaX = 20 + 2 = 22

── CONTEXTO DE USO EN EL SISTEMA GIS ───────────────────────────────────────────

  En Smallworld Physical Network Inventory, los objetos de la red (cables, ductos,
  empalmes) tienen un estado de construcción que determina cómo se muestran en el
  plano imprimible:

    PROYECTADO → rojo + negrita + escala mayor (diferencia claramente lo que aún
                 no está instalado físicamente)
    EXISTENTE  → verde + normal (lo que ya está en campo pero tiene algún estado
                 de proceso)
    sin estado  → negro + normal (estado base / sin clasificar)

  Este servicio es llamado por los métodos de dibujado de símbolos y etiquetas
  del Layout Designer antes de renderizar cada objeto, sustituyendo el estilo
  original por uno modificado según el estado del objeto.

── FLUJO DE USO ────────────────────────────────────────────────────────────────

  // Singleton (patrón original):
  const svc = CServiciosEstilos.singleton();

  // Caso 1: gis_text_style, PROYECTADO
  const gisStyle: GisTextStyle = {
    className: 'gis_text_style',
    actualTextStyles: { leftRight: { xscale:20, yscale:20, font:'plain', colour:COLOURS.black } }
  };
  const result = svc.obtenerEstiloBlancoYNegroTxt(gisStyle, 'PROYECTADO');
  // → { xscale:22, yscale:22, font:'bold', colour:{name:'red',hex:'#CC0000'} }

  // Caso 2: rwo_style, sin estado (_unset)
  const rwoStyle: RwoStyle = {
    className: 'rwo_style',
    actualTextStyle: { xscale:15, yscale:15, font:'plain', colour:COLOURS.black }
  };
  const result2 = svc.obtenerEstiloBlancoYNegroTxt(rwoStyle);
  // → { xscale:15, yscale:15, font:'plain', colour:{name:'black',hex:'#000000'} }

  // Caso 3: tipo desconocido → devuelve entrada sin modificar
  const unknown = { className: 'raw_symbol', data: '...' };
  const result3 = svc.obtenerEstiloBlancoYNegroTxt(unknown, 'EXISTENTE');
  // → { className: 'raw_symbol', data: '...' }  (misma referencia)

  <ServiciosEstilosUI />
