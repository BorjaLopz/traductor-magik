── QUÉ HACE ────────────────────────────────────────────────────────────────────

Configura y rellena el bloque de simbología de la red secundaria de fibra
óptica (FO) dentro del sello (cartucho / title block) de un plano de
construcción GIS.

Un "sello" en este contexto es el recuadro informativo que aparece en la
esquina de un plano técnico. Este componente define específicamente la sección
de simbología: el área del sello que explica los símbolos usados en el plano
(qué color/tipo de línea representa cada elemento de la red FO).

Métodos del ciclo de vida:
  1. configuraTablal() → define las tablas (rejilla de celdas) y sus dimensiones
  2. etiquetaCeldas()  → asigna texto o símbolo GIS a cada celda

── SÍMBOLO "simbologia_de_la_red_sec_fo" ───────────────────────────────────────

  En Smallworld este símbolo se carga desde la colección :sw_gis!gis_point_style
  con escala 3. No está definido en este fichero .magik.

  En la migración TS se representa como un componente SVG mock (SymboliogiaFoSvg)
  que muestra la leyenda típica de una red secundaria FO:
    - Líneas de colores para distintas capacidades (12/24/48 FO)
    - Líneas continuas para red existente
    - Líneas discontinuas para red proyectada
    - Punto/símbolo de cámara de empalme

  En producción se sustituiría por el símbolo real cargado desde
  SymbolStyleService.getSymbol('simbologia_de_la_red_sec_fo').

── FLUJO DE USO ────────────────────────────────────────────────────────────────

  // Solo lógica (sin render):
  const sello = new CSimbologiaPlanoContruccionFo();
  const { tables, cells } = sello.build();

  tables.get('tbl_contenido')
  // → { id:'tbl_contenido', rows:1, cols:1, rowHeights:[150], colWidths:[130] }

  cells.get('tbl_contenido:1:1')
  // → { type:'symbol', symbolName:'simbologia_de_la_red_sec_fo', scale:3 }

  // Componente demo React:
  <SimbologiaPlanoContruccionFoUI />
  // → Preview del sello con tbl_contenido activa + toggle para ver

  //   Símbolo FO renderizado como SVG con leyenda de colores/trazados
