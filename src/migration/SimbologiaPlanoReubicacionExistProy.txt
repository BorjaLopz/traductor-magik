── QUÉ HACE ────────────────────────────────────────────────────────────────────

Elemento de simbología embebible en planos de reubicación (existente/proyectado).
Es un "layout symbol" de Smallworld: un objeto que vive dentro de un plano
de impresión (plot layout) y sabe cómo dibujarse a sí mismo en el canvas de
Smallworld (ventana de plano) usando un símbolo GIS puntual configurable.

El símbolo se obtiene de la tabla :sw_gis!gis_point_style de la base de datos
:sigc_style_view (o del style_view global como fallback) y se renderiza con
5 transformaciones configurables por el usuario en el layout editor.

Diferencia clave vs [11] StyleSymbolOpenDialog:
  [11] tiene parámetros fijos (rotate=0, flipped=true, mirror=false) — es solo
  un diálogo de preview. Esta clase [19] es un elemento de plano con 5
  atributos editables, incluyendo override de color y ángulo variable.

── RELACIÓN CON OTRAS MIGRACIONES ──────────────────────────────────────────────

  [11] StyleSymbolOpenDialog  →  Exporta: SymbolDefinition, DrawSampleParams,
                                          drawSample(), SymbolStyleService
  [19] CSimbologiaPlanoReubicacionExistProy  →  Importa todo lo anterior.

  drawSample() de [11] se reutiliza directamente para el paso 9 del render.
  SymbolStyleService de [11] es la interfaz de inyección para la BD de símbolos.

  Diferencias respecto a [11]:
    [11] draw_preview:         rotate=0, flipped=true, mirror=false  (fijos)
    [19] draw_content_on:      rotate=f(angle), flipped=f(flip), mirror=f(mirror) (variables)
    [19] añade:                colour override (scaled_rgb_vector(100.0))
    [19] añade:                defined_attributes (5 descriptores de propiedades)
    [19] añade:                symbol_names (lista ordenada de símbolos)

── CONVERSIÓN DE COLOR ──────────────────────────────────────────────────────────

  Magik: colour.scaled_rgb_vector(100.0) → float_vec[3] con valores 0-100
  TS:    [number, number, number]         con valores 0-100 (mismo rango)

  Conversiones:
    RGB 0-100 → CSS:      rgb(r*2.55, g*2.55, b*2.55)
    CSS hex → RGB 0-100:  [(R/255)*100, (G/255)*100, (B/255)*100]

  Ejemplo: colour.called(:green) = [0.2*100, 0.6*100, 0*100] = [20, 60, 0]
    → CSS: rgb(51, 153, 0)

── LO QUE NO SE TRANSCRIBIÓ ────────────────────────────────────────────────────

- define_shared_constant(:allowed_on_menu?, _false, :public)
  → Metadato Smallworld. Sin equivalente TS.

- _super.defined_attributes (atributos de symbol_layout)
  → Son metadatos del motor de layout Smallworld (posición, tamaño, rotación a
    nivel de contenedor). Sin equivalente TS directo.

- c_simbologia_plano_reubicacion_exist_proy.define_attributes()
  → Llama al sistema de reflexión de Smallworld para registrar los atributos.
    En TS el registro se hace a través del array de AttributeDefinition.

- _pragma(classify_level=restricted, usage={redefinable})
  → Metadato Smallworld de accesibilidad. Sin equivalente TS.

- Slots del exemplar (escritura implícita):
  .name, .colour, .angle, .flip, .mirror → gestionados por el constructor
  y setAttribs() en TS.
