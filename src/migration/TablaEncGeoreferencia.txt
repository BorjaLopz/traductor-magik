── QUÉ HACE ────────────────────────────────────────────────────────────────────

Genera el bloque de encabezado de georeferencia del sello de plano. Este
encabezado es una composición de tres tablas posicionadas de forma relativa
entre sí, que en conjunto forman un bloque de 50 mm × 23 mm:

  ┌──────────────────────────────────┐  ← tbl_status: 50×15 mm (3 renglones × 2 cols)
  │       STATUS TERMINAL            │    renglón 1: celda(1,1) sin borde der. → fusión visual
  ├──────────────┬───────────────────┤    cols: [25, 25] mm
  │ C=CONECTADA  │  A=AUMENTO        │
  ├──────────────┼───────────────────┤
  │ S=SUSTITUIDA │  R=RESERVA        │
  ├──────┬───────┬───────────────────┤  ← tbl_terminal: 25×8 mm (1 renglón × 3 cols)
  │TERMI │STATUS │ DIST. A CEDO ↵    │    cols: [8, 6, 11] mm
  │NAL   │       │ (Mts)             │
  │      │       ├─────────┬─────────┤  ← tbl_georeferencia: 25×8 mm (2 reng × 2 cols)
  │      │       │ GEOREF. │         │    renglones: [3, 5] mm / cols: [11, 14] mm
  │      │       │ GEO     │  UTM    │
  └──────┴───────┴─────────┴─────────┘
  ← 25 mm →← 25 mm (tbl_georeferencia) →
  ← 50 mm total →

Contexto técnico:
  El encabezado de georeferencia es parte del sello (cartucho) del plano de
  tendido de fibra óptica. Recoge el estado de las terminales (conectada,
  aumento, sustituida, reserva) y los tipos de coordenadas (GEO / UTM) con
  los que está georeferenciado el plano. Color de línea verde (RGB 0.2,0.6,0)
  ≡ color corporativo de GE Network Solutions para planos físicos.

Magik: c_tabla_enc_georeferencia.configura_tabla()
TS:    CTablaEncGeoreferencia.configuraTablal(): void

  Las tres tablas se crean con posiciones calculadas a partir de .o_coord_inicio:

  Tabla               Posición Magik                                  TS
  ────────────────────────────────────────────────────────────────────────────────
  tbl_status (3×2)    oCoordenada_Origen << .o_coord_inicio           { ...orig }
  tbl_terminal (1×3)  coordinate.new(x, y - ln_desp_y)               { x, y-despY }
  tbl_georef   (2×2)  coordinate.new(x + ln_desp_x, y - ln_desp_y)   { x+despX, y-despY }

  donde:
    ln_desp_y = longitud_total_renglones({:tbl_status}) = 5+5+5 = 15 mm
    ln_desp_x = longitud_total_columnas({:tbl_terminal}) = 8+6+11 = 25 mm

  Equivalencias Magik → TypeScript:

  Magik                                                TypeScript
  ──────────────────────────────────────────────────   ────────────────────────────────

  .o_tablas.crea_tabla(3,2,:tbl_status)                 crearTabla(3, 2, 'tbl_status', ...)
  lo_tabla.oCoordenada_Origen << coord                  setTableLayout(id, origen, color)
  lo_tabla.color_linea << rope.new_with(0.2,0.6,0)      colorLinea: [0.2,0.6,0]

── LO QUE NO SE TRANSCRIBIÓ ────────────────────────────────────────────────────

- define_shared_constant(:allowed_on_menu?, ...)
  → Metadato Smallworld de visibilidad en menús. Sin equivalente TS.

- _private / _pragma(classify_level=advanced)
  → Accesibilidad y metadatos Smallworld. Sin equivalente en TS.
  → Los métodos son protected en la jerarquía TS.

- rope.new_with(r,g,b) → array TypeScript [number,number,number]
  La conversión a CSS se hace con rgb01() en el componente React.

- property_list.new() → objeto literal TypeScript (no hay clase PropertyList).

- coordinate.new(x,y) → objeto literal { x: number; y: number }.

- _self.etiqueta_celdas() dentro de configura_tabla()
  → En TS, la llamada se separa en buildLayout() para mejor control de orden.
    configuraTablal() solo crea tablas; etiquetaCeldas() solo asigna textos.
