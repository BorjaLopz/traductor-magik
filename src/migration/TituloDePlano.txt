── QUÉ HACE ────────────────────────────────────────────────────────────────────

Caja de título de plano (textbox) que se auto-posiciona en la esquina
inferior-derecha del bounding box del área contenedora (oBoundContenedor).

Uso típico en el Layout Designer de Smallworld: el plano tiene un contenedor
que ocupa toda la hoja, y el título se coloca automáticamente en la esquina
inferior-derecha con un margen fijo de 400 unidades en X e Y.

── SLOTS ────────────────────────────────────────────────────────────────────────

  oBoundContenedor  {_unset, :writable, :private}
    Bounding box del área contenedora del plano.
    Con setter validado: solo acepta objetos bounding_box válidos.

  sEscala  {_unset, :writable}
    Escala del plano (p.ej. "1:500"). Declarada en el Magik original
    pero no usada en los métodos visibles — disponible para uso externo.

── MÉTODOS TRANSCRITOS ─────────────────────────────────────────────────────────

Magik: c_titulo_de_plano.oBoundContenedor<<PoBoundingBox
TS:    set oBoundContenedor(bb: BoundingBox | null)

  Magik:
    write("PoBoundingBox---", PoBoundingBox.ap(:cor))     → debug log
    _if PoBoundingBox.is_kind_of?(bounding_box) _then
        .oBoundContenedor << PoBoundingBox
    _else
        .oBoundContenedor << _unset
    _endif

  TS:
    console.log('PoBoundingBox---', bb)                   → mismo log debug
    this._oBoundContenedor = isBoundingBox(bb) ? bb : null
    isBoundingBox() valida que bb tenga xMin/xMax/yMin/yMax numéricos.

────────────────────────────────────────────────────────────────────────────────

Magik: c_titulo_de_plano.draw_content_on(window)
TS:    drawContentOn(): void

  1. Si oBoundContenedor _isnt _unset:
     Calcula nuevo self.bounds colocando el título en esquina inferior-derecha:

     Magik (Y-up, yMin = borde inferior):
       LoBound = bounding_box.new(
         c.xMax - 400 - self.bounds.width,   ← xMin
         c.yMin + 400,                        ← yMin  (400u sobre borde inferior)
         c.xMax - 400,                        ← xMax
         c.yMin + 400 + self.bounds.height    ← yMax
       )

     SVG (Y-down, yMax = borde inferior):
       xMin = c.xMax - 400 - w    (igual)
       yMin = c.yMax - 400 - h    (yMin Magik → yMax SVG, invertido)
       xMax = c.xMax - 400        (igual)
       yMax = c.yMax - 400        (yMax Magik → yMin SVG, invertido)

  2. _super.draw_content_on(window) — renderiza el contenido textual heredado.

── CONSTANTE OFFSET ────────────────────────────────────────────────────────────

  400 unidades hardcodeadas en el Magik original para ambos ejes.
  En TypeScript: TituloDePlano.OFFSET = 400 (constante estática readonly).
  Corresponde a la distancia de separación respecto a los bordes del contenedor.

── CONVERSIÓN DE COORDENADAS ───────────────────────────────────────────────────

  Magik usa Y-up (GIS estándar): yMin es el borde inferior del bbox.
  SVG  usa Y-down:               yMax es el borde inferior del bbox.

  La posición resultante es equivalente en ambos sistemas:
  el título aparece en la esquina inferior-derecha del contenedor.

  Magik: c.yMin + OFFSET       → cerca del borde inferior (Y-up)
  SVG:   c.yMax - OFFSET - h   → cerca del borde inferior (Y-down)

── LO QUE NO SE TRANSCRIBIÓ ────────────────────────────────────────────────────

- defined_attributes(): solo llama _super.defined_attributes — boilerplate
  Smallworld. No tiene lógica de negocio, no se transcribe.

- define_shared_constant(:activate_properties_dialog_on_insert?, _false):
  Hook del framework Smallworld para controlar si abre diálogo al insertar
  el elemento. Sin equivalente en React.

- define_shared_constant(:allowed_on_menu?, _false):
  Hook de control de visibilidad en menús de Smallworld. Sin equivalente.

- Herencia completa de textbox_layout: se define un stub mínimo.
  Cuando se migre textbox_layout.magik, sustituir el stub por el import.

── DEMO INTERACTIVO ─────────────────────────────────────────────────────────────

El componente React <TituloDePlanoUI /> muestra:
  - Sliders para ancho y alto del contenedor (en unidades de layout).
  - Sliders para ancho y alto del título (self.bounds iniciales).
  - Inputs para texto del título y escala.
  - Checkbox para simular setter inválido → oBoundContenedor = _unset.
  - SVG que renderiza contenedor (azul oscuro) + título (azul claro) auto-posicionado.
  - Líneas de anotación mostrando el OFFSET=400u en ambos ejes.
  - Cuadro inferior con self.bounds calculados tras drawContentOn().

── FLUJO DE USO ────────────────────────────────────────────────────────────────

  const titulo = new TituloDePlano();
  titulo.titulo  = 'Plano Red Óptica — Madrid Norte';
  titulo.sEscala = '1:500';
  titulo.bounds  = { xMin: 0, xMax: 1000, yMin: 0, yMax: 400 };  // tamaño del título

  // Asignar contenedor (setter valida is_kind_of?(bounding_box)):
  titulo.oBoundContenedor = { xMin: 0, xMax: 4000, yMin: 0, yMax: 2800 };

  // Calcular posición:
  titulo.drawContentOn();

  // Resultado:
  // titulo.bounds = { xMin: 2600, yMin: 2000, xMax: 3600, yMax: 2400 }
  // → esquina inferior-derecha del contenedor (400u de offset)

  // Setter inválido:
  titulo.oBoundContenedor = null;   // → _unset, sin repositionamiento
  titulo.drawContentOn();           // → bounds sin cambio
