── QUÉ HACE ────────────────────────────────────────────────────────────────────

Es una utilidad de traducción/abreviación que convierte claves internas del
sistema GIS (símbolos Magik) a cadenas de texto para planos impresos.

No realiza cálculos espaciales ni interactúa con el mapa (no Turf.js, no OL).
Es una clase de lookup puro: entrada = clave GIS, salida = texto de plano.

Contiene 7 tablas de traducción independientes:

  ┌─────────────────────────────┬──────────────────────────────────────────────┐
  │ Método Magik                │ Descripción                                  │
  ├─────────────────────────────┼──────────────────────────────────────────────┤
  │ Tipo_Superficie(clave)      │ Nombre de superficie → abreviatura de plano  │
  │                             │ ej. "Adoquin" → "ADOQ."                      │
  ├─────────────────────────────┼──────────────────────────────────────────────┤
  │ Mes(numero, largo?)         │ Número de mes 1-12 → nombre español          │
  │                             │ ej. 9 → "SEP" / "SEPTIEMBRE"                │
  ├─────────────────────────────┼──────────────────────────────────────────────┤
  │ Tipo_Central(clave)         │ Tipo de central → código abreviado           │
  │                             │ ej. "GABINETE" → "NAM"                       │
  ├─────────────────────────────┼──────────────────────────────────────────────┤
  │ metodo_pep(clave)           │ Clave larga de método PEP → código corto     │
  │                             │ ej. "pep_construccion_canalizacion"          │
  │                             │     → "pep_cons_can"                         │
  ├─────────────────────────────┼──────────────────────────────────────────────┤
  │ tipo_plano(clave)           │ ID de tipo de plano → nombre completo        │
  │                             │ ej. "itinerario" → "ITINERARIO DE            │
  │                             │                     CANALIZACION"            │
  ├─────────────────────────────┼──────────────────────────────────────────────┤
  │ tipo_caseta(descripcion)    │ Descripción larga de caseta → código corto   │
  │                             │ ej. "TELEFONO PUBLICO TARJETA CHIP TPTC"    │
  │                             │     → "TPTC"                                 │
  ├─────────────────────────────┼──────────────────────────────────────────────┤
  │ nombre_atributo_pep(clave)  │ Nombre simbólico PEP → nombre de campo DB    │
  │                             │ ej. "PEPFibraAereaUT" → "user!_pep_ut_fib_ae"│
  └─────────────────────────────┴──────────────────────────────────────────────┘

Contexto técnico:
  En Smallworld GIS los valores de atributos se almacenan como símbolos Magik
  (:symbol o :|symbol con espacios|). Al generar planos impresos, estos valores
  deben convertirse a textos abreviados o completos para caber en las celdas
  del Layout Designer. c_Traductor centraliza todas esas conversiones.

── PATRÓN DE INICIALIZACIÓN ────────────────────────────────────────────────────

  Magik usa _clone.init() — en TS se reemplaza por constructor implícito:

  Magik                                  TypeScript
  ──────────────────────────────────── ────────────────────────────────────────
  _method c_Traductor.new()            const t = new CTraductor()
    _return _clone.init()              // no factory async necesario:
  _endmethod                           // no hay IO en la inicialización

  _method c_Traductor.init()
    _return _self                      // constructor vacío, slots null
  _endmethod

── MÉTODOS TRANSCRITOS ─────────────────────────────────────────────────────────

────────────────────────────────────────────────────────────────────────────────
Magik: c_Traductor.Tipo_Superficie(PsTipo_Sup)
TS:    CTraductor.tipoSuperficie(tipoSup: string): string
────────────────────────────────────────────────────────────────────────────────

  Patrón: lazy-init (solo crea la tabla la primera vez).

  Magik                                            TypeScript
  ──────────────────────────────────────────────   ────────────────────────────
  _if .oTabla_Sup _is _unset _then                 if (this.tablaSup === null) {
    .oTabla_Sup << hash_table.new()                  this.tablaSup = new Map([...])
    .oTabla_Sup.default_value << ""                }
    .oTabla_Sup[:|Adoquin|] << "ADOQ."             return this.tablaSup.get(tipoSup) ?? ''
  _endif
  _return .oTabla_Sup[PsTipo_Sup]

  .default_value "" → fallback ?? '' en el .get()
  Símbolos :|Adoquin| (con pipe porque tienen mayúscula inicial) → string key 'Adoquin'
  15 entradas incluyendo "Pasto (Area Jardinada)" con espacios y paréntesis.

────────────────────────────────────────────────────────────────────────────────
Magik: c_Traductor.Mes(PnNumeroMes, _optional formato_largo?)
TS:    CTraductor.mes(numeroMes: number, formatoLargo = false): string
────────────────────────────────────────────────────────────────────────────────

  PATRÓN ESPECIAL: el Magik original NO tiene "_if .oTabla_Mes _is _unset".
  Reconstruye la tabla en CADA llamada. Esto es intencional para admitir
  cambio de formato (corto/largo) entre llamadas sin riesgo de cache obsoleta.

  Magik                                            TypeScript
  ──────────────────────────────────────────────   ────────────────────────────
  .oTabla_Mes << hash_table.new()                  // siempre reconstruye
  _if formato_largo? = _true _then                 const nombres = formatoLargo
    .oTabla_Mes[1] << "ENERO" ...                    ? ['ENERO',...,'DICIEMBRE']
  _else                                              : ['ENE',...,'DIC']
    .oTabla_Mes[1] << "ENE" ...                    this.tablaMes = new Map(...)
  _endif                                           return this.tablaMes.get(n) ?? ''
  _return .oTabla_Mes[PnNumeroMes]

  Claves: enteros 1-12 → Map<number,string>
  formato_largo? = _true (Magik) → formatoLargo = false (TS default)

────────────────────────────────────────────────────────────────────────────────
Magik: c_Traductor.Tipo_Central(PsTipoCtl)
TS:    CTraductor.tipoCentral(tipoCtl: string): string
────────────────────────────────────────────────────────────────────────────────

  Patrón: lazy-init con default_value "CTL" (≠ "" de las otras tablas).

  Magik                                            TypeScript
  ──────────────────────────────────────────────   ────────────────────────────
  .oTabla_TipoCtl.default_value << "CTL"           ?? 'CTL'
  .oTabla_TipoCtl[:CENTRAL]    << "CTL"            Map(['CENTRAL','CTL'],...)
  .oTabla_TipoCtl[:CONTENEDOR] << "URL"
  .oTabla_TipoCtl[:GABINETE]   << "NAM"

  Claves Magik son símbolos simples (:CENTRAL) → string keys 'CENTRAL'.
  "DESCONOCIDO" u otras claves no mapeadas devuelven "CTL" por defecto.

────────────────────────────────────────────────────────────────────────────────
Magik: c_Traductor.metodo_pep(PsPEPSel)
TS:    CTraductor.metodoPep(pepSel: string): string | undefined
────────────────────────────────────────────────────────────────────────────────

  Patrón: lazy-init SIN default_value → undefined si clave no existe.

  11 entradas que mapean nombres largos de método PEP a códigos cortos:
    pep_construccion_canalizacion   → pep_cons_can
    pep_rehabilitacion_secundaria   → pep_reha_sec
    ...etc.

  La ausencia de default_value en Magik → .get() sin fallback → undefined en TS.

────────────────────────────────────────────────────────────────────────────────
Magik: c_traductor.tipo_plano(Id_Tipo_Plano)
TS:    CTraductor.tipoPlano(idTipoPlano: string): string
────────────────────────────────────────────────────────────────────────────────

  Patrón: lazy-init con default_value "" → ?? ''
  8 entradas. Nota: 'ruta_cables' y 'ruta_cables_fo' devuelven el mismo
  texto "RUTA DE CABLES" — comportamiento fiel al Magik original.

────────────────────────────────────────────────────────────────────────────────
Magik: c_Traductor.tipo_caseta(p_descripcion)
TS:    CTraductor.tipoCaseta(descripcion: string): string
────────────────────────────────────────────────────────────────────────────────

  Patrón: lazy-init con default_value "" → ?? ''

  Las claves Magik usan la sintaxis :|texto con espacios y siglas| para símbolos
  con espacios. En TypeScript son simplemente strings:

  Magik                                            TypeScript
  ──────────────────────────────────────────────   ────────────────────────────
  :|TELEFONO PUBLICO TARJETA CHIP TPTC|            'TELEFONO PUBLICO TARJETA CHIP TPTC'
  → :|TPTC|                                        → 'TPTC'

  Los valores de salida también son :|PSLT| etc. en Magik (símbolos).
  En TS se convierten a string 'PSLT', 'TPTC', 'LTC', 'OPERT'.

────────────────────────────────────────────────────────────────────────────────
Magik: c_traductor.nombre_atributo_pep(psym_nombre_pep)
TS:    CTraductor.nombreAtributoPep(nombrePep: string): string | undefined
────────────────────────────────────────────────────────────────────────────────

  PATRÓN ESPECIAL: crea una hash_table LOCAL (variable local, no slot).
  No hay lazy-init, no hay slot de instancia. Nueva tabla en cada llamada.

  Magik                                            TypeScript
  ──────────────────────────────────────────────   ────────────────────────────
  _local lht_attr_pep << hash_table.new()          const tabla = new Map([...])
  lht_attr_pep[:|PEPFibraAereaUT|]                 tabla.get('PEPFibraAereaUT')
    << "user!_pep_ut_fib_ae"
  _return lht_attr_pep[psym_nombre_pep]

  8 entradas. Mapea nombres de atributos UI (simbólicos) a campos de la base
  de datos GIS (user!_pep_ut_cana_ali, etc.).
  Sin default_value → undefined si no existe la clave.

── DIFERENCIAS CRÍTICAS ENTRE MÉTODOS ──────────────────────────────────────────

  Comportamiento  │ Método(s) afectados
  ────────────────┼────────────────────────────────────────────────────────────
  Lazy-init       │ tipoSuperficie, tipoCentral, metodoPep, tipoPlano, tipoCaseta
  Reconstruye     │ mes() — siempre, por diseño (soporte formato largo/corto)
  cada llamada    │ nombreAtributoPep() — tabla local, no slot
  ────────────────┼────────────────────────────────────────────────────────────
  Default ""      │ tipoSuperficie, tipoPlano, tipoCaseta
  Default "CTL"   │ tipoCentral
  Sin default     │ metodoPep, nombreAtributoPep → undefined
  (→ en TS)

── LO QUE NO SE TRANSCRIBIÓ ────────────────────────────────────────────────────

- #remex(:c_Traductor) (comentado en el original)
  → Recarga en caliente de Smallworld. No aplica en TS compilado.

- _pragma(classify_level=restricted, usage={redefinable})
  → Metadatos de clasificación del Layout Designer de Smallworld.
    Sin equivalente en TypeScript.

- def_slotted_exemplar con 6 slots {:writable}
  → Los slots se convierten en propiedades de instancia privadas tipadas.
    El modificador :writable (acceso público de escritura en Magik) se
    privatiza en TS; la escritura ocurre solo dentro de los métodos.

- hash_table.default_value
  → No existe en Map<K,V>. Se emula con el operador ?? en cada .get().

- Símbolos Magik (:symbol, :|symbol con espacios|)
  → No existen en TypeScript. Se convierten directamente a string literals.
    Los :|pipes con espacios| son obligatorios en Magik cuando el símbolo
    contiene caracteres no alfanuméricos; en TS son strings normales.

- _optional formato_largo?
  → Parámetro opcional de Magik → parámetro con valor por defecto en TS:
    _optional formato_largo? → formatoLargo = false

── FLUJO DE USO ────────────────────────────────────────────────────────────────

  // Instanciación simple (sin async, sin factory):
  const t = new CTraductor();

  // Superficie:
  t.tipoSuperficie('Adoquin')        // → "ADOQ."
  t.tipoSuperficie('Tierra Limpia')  // → "TIERRA"
  t.tipoSuperficie('Desconocida')    // → ""  (default)

  // Mes:
  t.mes(9)             // → "SEP"
  t.mes(9, true)       // → "SEPTIEMBRE"
  t.mes(13)            // → ""  (fuera de rango)

  // Central:
  t.tipoCentral('GABINETE')       // → "NAM"
  t.tipoCentral('DESCONOCIDA')    // → "CTL" (default)

  // Método PEP:
  t.metodoPep('pep_construccion_canalizacion')  // → "pep_cons_can"
  t.metodoPep('pep_xxx')                        // → undefined

  // Tipo de plano:
  t.tipoPlano('ruta_cables')   // → "RUTA DE CABLES"
  t.tipoPlano('ashurado')      // → "ASHURADO"

  // Caseta:
  t.tipoCaseta('TELEFONO PUBLICO COMPETENCIA')  // → "OPERT"

  // Atributo PEP:
  t.nombreAtributoPep('PEPFibraAereaZO')   // → "user!_pep_zo_fib_ae"
  t.nombreAtributoPep('PEPDesconocido')    // → undefined

  // Componente demo React:
  <TraductorUI />
  // → Selector de método (7 opciones)
  //   Selector de valor de entrada (poblado dinámicamente)
  //   Checkbox para formato largo (solo visible en método Mes)
  //   Botón "Traducir" → muestra resultado inline
  //   Sección expandible con todas las tablas de traducción completas
