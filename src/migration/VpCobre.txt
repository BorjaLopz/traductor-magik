── QUÉ HACE ────────────────────────────────────────────────────────────────────

Es un viewport layout especializado para planos de red de cobre. Un "viewport
layout" en Smallworld es un elemento de la página del Layout Designer que
muestra un recorte del mapa GIS. Esta clase añade dos capacidades sobre la
clase base (viewport_layout):

  1. FILTRADO ESPACIAL: cuando se define una zona límite (oLimite, el polígono
     que delimita el área de estudio de población), solo se muestran los objetos
     GIS que intersectan con esa zona. Los demás se excluyen del renderizado.

  2. MARCAS DE ESQUINA: el método DibujarMarcas genera cuatro "L" en las
     esquinas del viewport (con sangrías de 200 u.m. por lado). Con el flag
     PbMarcoCompleto=true, los sectores se encadenan formando un marco continuo.

  Layout visual del viewport con marcas:

  EQUIVALENCIA CLAVE:
    pseudo_area.new_with_sectors(oLimite.sectors) crea un área poligonal
    a partir de los sectores geométricos del atributo oLimite.
    En GeoJSON/Turf, oLimite ya ES un Feature<Polygon>, por lo que
    turf.booleanIntersects() lo usa directamente sin paso previo de conversión.

    select(:overlaying, area) = filtra los objetos del result_set que
    se solapan (intersectan) con el área.
    → turf.booleanIntersects(feature, oLimite) devuelve true si hay intersección.

    Funciona para LineString (cables), Point (empalmes) y Polygon (otras zonas).

  PASO 2 — Construcción de las 4 esquinas:

    Las marcas son sectores (polilíneas) en forma de "L". Cada sector describe
    los 3 puntos del ángulo de la esquina. Con marcoCompleto=true, se añade
    un 4º punto que conecta con el inicio de la siguiente esquina.

    a = PnAncho (longitud del trazo de la marca)

    Esquina              P0                    P1             P2                  P3 (marcoCompleto)
    ─────────────────── ──────────────────── ──────────────── ───────────────── ──────────────────────
    Inferior izquierda  (xmin, ymin+a) ↑     (xmin, ymin) ◄  (xmin+a, ymin) →  (xmax-a, ymin)
    Inferior derecha    (xmax-a, ymin) →     (xmax, ymin) ◄  (xmax, ymin+a) ↑  (xmax, ymax-a)
    Superior derecha    (xmax, ymax-a) ↑     (xmax, ymax) ◄  (xmax-a, ymax) →  (xmin+a, ymax)
    Superior izquierda  (xmin+a, ymax) →     (xmin, ymax) ◄  (xmin, ymax-a) ↓  (xmin, ymin+a)

    Sin marcoCompleto: 4 marcas independientes en L (3 puntos cada una).
    Con marcoCompleto: cada L se extiende hasta el inicio de la siguiente,
    formando un rectángulo completo con énfasis en las esquinas.

    P3 de cada esquina coincide exactamente con P0 de la siguiente:
      Inf.izq  P3 = (xmax-a, ymin)  ← mismos que inf.der  P0
      Inf.der  P3 = (xmax, ymax-a)  ← mismos que sup.der  P0
      Sup.der  P3 = (xmin+a, ymax)  ← mismos que sup.izq  P0
      Sup.izq  P3 = (xmin, ymin+a)  ← mismos que inf.izq  P0

── LO QUE NO SE TRANSCRIBIÓ ────────────────────────────────────────────────────

- !current_coordinate_system! << _unset
  → Variable dinámica de Magik (contexto de llamada). Fuerza coordenadas sin
    transformación de sistema de referencia. En TypeScript/OL el sistema de
    referencia se gestiona a nivel de mapa (ol/proj), no como variable global
    de contexto. Se omite.

- _dynamic  (declarador de variable dinámica)
  → Concepto exclusivo de Magik. Sin equivalente directo en TS.

- PoPage.default(_self).bounds
  → Accede a la página del layout para obtener sus bounds. En TS se pasa como
    parámetro opcional (bounds?) con fallback a bounds por defecto.

- Llamada a DibujarMarcas en draw_content_on (comentada en el original)
  → Se mantiene comentada exactamente igual.

- Posicionamiento del norte (LoNorte.limites = ...) — código comentado original
  → Se mantiene como comentario de referencia histórica.

- sector_rope.draw_on(window, colour.called(:black))
  → Dibujado directo en la ventana Smallworld. En TS se devuelven
    Feature<LineString>[] para que el cliente los añada al mapa OL.

- _pragma(classify_level=restricted)
  → Metadato de accesibilidad Smallworld. Sin equivalente TS.

  // Solo lógica:
  const vp = new CVpCobre();
  vp.oLimite = miPoligonoLimite;  // Feature<Polygon> GeoJSON

  // Filtrado de objetos (geometry_set_for_render)
  const featuresVisible = vp.geometrySetForRender(todasLasFeatures);
  // → solo las que intersectan con oLimite

  // Marcas de esquina (sin marco completo)
  const marcas = vp.dibujarMarcas(200, { xmin:0, ymin:0, xmax:1400, ymax:1000 }, false);
  // → 4 × Feature<LineString> (L-shapes)

  // Con marco completo:
  const marco = vp.dibujarMarcas(200, bounds, true);

  // Añadir al mapa OL:
  vp.addMarcasToSource(200, bounds, false);
