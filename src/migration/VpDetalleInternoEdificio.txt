── QUÉ HACE ────────────────────────────────────────────────────────────────────

Viewport de detalle interno de edificio para planos de red física (TBA).
Un viewport es una ventana dentro del plano que muestra una vista geográfica
específica. Este en concreto:
  - Muestra la planta interior de un edificio (TBA = Telecommunications Building Access)
  - Usa el grupo de estilos ACE :mit_floor_internal
  - Obtiene las geometrías sin transformación de sistema de coordenadas
    (!current_coordinate_system! = _unset)
  - Añade una barra de título "DETALLE DE EDIFICIO" de 100 unidades de alto
    colocada justo debajo del área del viewport

── MÉTODOS TRANSCRITOS ─────────────────────────────────────────────────────────

Magik: c_vp_detalle_interno_edificio.initialise_for_page(a_layout_page)
TS:    initializeForPage(page: ILayoutPage): void

  1. Asigna el ACE (Access Control Entity): _self.ace_name << :mit_floor_internal
     TS: this.aceName = 'mit_floor_internal'
  2. Llama a agregar_titulo(a_layout_page)
     TS: this.agregarTitulo(page)

────────────────────────────────────────────────────────────────────────────────

Magik: c_vp_detalle_interno_edificio.geometry_set_for_render
TS:    geometrySetForRender(): EdificioFeatureCollection

  1. Unset del sistema de coordenadas dinámico:
     Magik: !current_coordinate_system! << _unset
     TS: comentario explicativo — en OL equivale a usar CRS nativo sin reproyectar
  2. Llama a _super.geometry_set_for_render y almacena en .oResulSet
     TS: MOCK_FLOOR_PLAN (7 features GeoJSON con planta de edificio)

  oResulSet: slot público writable que guarda el composite_geometry_set resultante.

────────────────────────────────────────────────────────────────────────────────

Magik: c_vp_detalle_interno_edificio.draw_content_on(windows)
TS:    drawContentOn(): void

  Delegación pura a super: _super.draw_content_on(windows)
  TS: this.superDrawContentOn()
  Sin lógica propia — el método existe para poder sobreescribirse en subclases.

────────────────────────────────────────────────────────────────────────────────

Magik: c_vp_detalle_interno_edificio.agregar_titulo(PoPage)
TS:    agregarTitulo(page: ILayoutPage): void

  1. Crea bounding_box para la barra de título:
     Magik: bounding_box.new(xmin, ymin-100, xmax, ymin)
     → título de 100 unidades de alto, colocado DEBAJO del viewport (Y-up Magik)
     TS: { xMin, yMin: bounds.yMax, xMax, yMax: bounds.yMax + 100 }
     → conversión Y-up → Y-down: "debajo" en Magik = yMax+100 en SVG

  2. Crea c_titulo_de_plano (ver migración [12]):
     Propiedades:
       text:             "DETALLE DE EDIFICIO"
       fontName:         "bold"
       fontSize:         tamanio (= 8u constante de clase)
       fillStyle:        null (_unset)
       outlineStyle:     null (_unset)
       wrap:             false (_false)
       alignHorizontal:  'centre'
       alignVertical:    'centre'
       orientation:      'left_right'

  3. Añade el elemento al plano: PoPage.add_element(LoTitulo)
     TS: page.addElement(tituloEl)

── CONSTANTES Y VARIABLES DE CLASE ─────────────────────────────────────────────

  titulo         = ""     (define_shared_variable — editable en runtime)
  TAMANIO        = 8      (define_shared_constant — fuente del título)
  ALLOWED_ON_MENU = false (define_shared_constant — no aparece en menús)
  ACE_NAME       = 'mit_floor_internal' (estilo de plano para planta interior)

── DATOS MOCK — composite_geometry_set ──────────────────────────────────────────

  MOCK_FLOOR_PLAN contiene 7 features GeoJSON Polygon representando:
    muro_exterior    → contorno del edificio
    sala_principal   → sala TBA principal
    rack (×3)        → Rack A, Rack B, Rack C (equipos de telecomunicaciones)
    corredor         → corredor de servicio
    acceso           → zona de entrada entre sala y corredor

  En producción: obtenidas de la BD GIS usando el ACE :mit_floor_internal
  que filtra las geometrías del tipo "planta de edificio" correspondientes
  al edificio TBA en cuestión.

── CONVERSIÓN DE COORDENADAS ────────────────────────────────────────────────────

  Magik usa Y-up (Y crece hacia arriba):
    bounding_box.new(xmin, ymin-100, xmax, ymin)
    → la barra de título está en [ymin-100, ymin] = 100u POR DEBAJO del viewport

  SVG usa Y-down (Y crece hacia abajo):
    { yMin: bounds.yMax, yMax: bounds.yMax + 100 }
    → misma posición "debajo del viewport" en coordenadas SVG

── DEMO INTERACTIVO ─────────────────────────────────────────────────────────────

  <VpDetalleInternoEdificioUI /> muestra:
    - Input de texto del título (editable)
    - Input de font_size (tamanio)

── LO QUE NO SE TRANSCRIBIÓ ────────────────────────────────────────────────────

  - viewport_layout completo (base Smallworld no modelada).
  - Integración con el motor de planos de Smallworld (layout engine).
  - Acceso real a la BD GIS para obtener geometrías por ACE.
  - Gestión real de !current_coordinate_system! como variable dinámica.
  - _self.view_scale << 5000 (comentado en el original Magik, no implementado).
  - Conexión con c_titulo_de_plano real (se usa TituloConfig inline).
