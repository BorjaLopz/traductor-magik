-- QUE HACE -------------------------------------------------------------------

Calcula el centro del area y dibuja un circulo con un estilo de linea.

-- METODOS TRANSCRITOS ---------------------------------------------------------

Magik: new()
TS:    CirculoGrafico.create(area)

Equivalencia:
  - _clone -> new CirculoGrafico(area)

-----------------------------------------------------------------------

Magik: Despliega()
TS:    CirculoGrafico.despliega()

Equivalencias directas:
  - LnX/LnY = centro del area -> cx/cy
  - line_style.new_with_properties(:foreground_colour, black, :width, 2)
    -> style { color: '#000000', width: 2 }
  - draw_circle_transform -> render de circulo (SVG en la demo)

-----------------------------------------------------------------------

Magik: nRadio << RnValor
TS:    CirculoGrafico.setRadio(valor)

Equivalencia:
  - nRadio << RnValor * 10 -> nRadio = valor * 10

-- COMPONENTE REACT ------------------------------------------------------------

CirculoGraficoUI
  - Permite ajustar el radio base.
  - Dibuja un circulo en un SVG de 100x100.
  - Muestra la regla de escala (x10).

-- LO QUE NO SE TRANSCRIBIO ----------------------------------------------------

- Integracion real con oVentana.draw_circle_transform de Smallworld.
