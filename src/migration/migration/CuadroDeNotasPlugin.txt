-- QUE HACE -------------------------------------------------------------------

Registra la accion del plugin y activa el dialogo "cuadro de notas",
cacheando la instancia para reutilizacion.

-- METODOS TRANSCRITOS ---------------------------------------------------------

Magik: init_actions()
TS:    CuadroDeNotasPlugin.initActions()

Equivalencias directas:
  - add_action(sw_action.new(...)) -> expuesto como metodo; el boton llama activateDialog()

-----------------------------------------------------------------------

Magik: build_gui(a_frame, xml_element)
TS:    CuadroDeNotasPlugin.buildGui()

Equivalencias directas:
  - cuadro_de_notas_framework.new(...) -> DialogDescriptor basico
  - tab_label -> tabLabel

-----------------------------------------------------------------------

Magik: activate_dialog(_gather args)
TS:    CuadroDeNotasPlugin.activateDialog()

Equivalencias directas:
  - get_dialog/cache_dialog -> cache local (Map)
  - maximizable?/minimizable?/resizable? -> flags en DialogDescriptor
  - activate(top_frame, "un mensaje") -> message en DialogDescriptor

-- COMPONENTE REACT ------------------------------------------------------------

CuadroDeNotasPluginUI
  - Boton para abrir el dialogo.
  - Muestra la metadata del dialogo y permite cerrar.

-- LO QUE NO SE TRANSCRIBIO ----------------------------------------------------

- Framework real de GUI y archivos gui.xml/config.xml.
- Sistema de acciones y cache de Smallworld.
