── QUÉ HACE ────────────────────────────────────────────────────────────────────

Elemento gráfico de DIAGRAMA (croquis/layout) que representa un empalme de
cobre en planos de red de telecomunicaciones.

NO es un objeto de mapa OL. Vive en un viewport de impresión/croquis.
Equivale a un componente SVG posicionado dentro de un bounding box.

Cuando se instancia con una entidad (numEmpalme), produce un símbolo visual:
  - Una línea horizontal (el cable)
  - Un rombo central (símbolo estándar de empalme en planos telecom)
  - Una etiqueta de texto con el código "ER-{numEmpalme}"

El layout interno divide el bounding box en 20 filas y calcula los márgenes
superiores e inferiores de cada elemento a partir de su posición en esas filas.

── MÉTODOS TRANSCRITOS ─────────────────────────────────────────────────────────

Magik: c_elemento_empalme_g.new(RoObjeto)
TS:    constructor(entidad: EntidadEmpalme)

  Inicializa los slots heredados de c_elemento_entidad_g:
    sNombreSimbol = "empalme de cobre"
    sDescripcion  = "ER-" + entidad.numEmpalme
    nLongGrafica  = 20
  En Magik: _super.new(RoObjeto) + asignación directa de slots.
  En TS: constructor que recibe la entidad GIS y calcula la descripción.

────────────────────────────────────────────────────────────────────────────────

Magik: c_elemento_empalme_g.Crea_elementos_internos()  [private]
TS:    private creaElementosInternos()

  Crea los dos elementos gráficos internos:
    - Etiqueta_1: c_texto_grafico.new("ER"), tamaño 25, alineación centre_centre
                  Posición en collEtiquetas: 14 (base para cálculo de márgenes)
    - Simbolo_1:  c_simbolo_grafico.new("empalme de cobre")
  En Magik: usa oElementos.Agregar_elemento(obj, :clave).
  En TS:    popula el objeto oElementos con las dos entradas.

────────────────────────────────────────────────────────────────────────────────

Magik: c_elemento_empalme_g.dfn_ubicacion_elementos_internos()
TS:    private dfnUbicacionElementosInternos()

  Calcula márgenes superior e inferior de cada elemento dentro del bounding box.
  Lógica:
    altRen = (yMax - yMin) / 20          <- altura de 1 fila
    Etiqueta_1:
      nMargenSup = altRen * (14 / 10)    <- pos_etiqueta(:Etiqueta_1) = 14
      nMargenInf = altRen * (4 / 10)     <- 20 - 2 - 14 = 4
    Simbolo_1:
      LnNumRenSup = 5 - 4 = 1
      LnNumRenInf = 15 + 4 = 19
      (En el Magik original los márgenes del símbolo se calculan pero
       no se asignan — el método está incompleto en el fuente original)

────────────────────────────────────────────────────────────────────────────────

Magik: c_elemento_empalme_g.configurar_elementos()
TS:    configurarElementos()

  Punto de entrada principal. Orquesta:
    1. creaElementosInternos()         <- Crea_elementos_internos()
    2. dfnUbicacionElementosInternos() <- posiciona en el grid de 20 filas
    3. Etiqueta_1.texto = sDescripcion <- LoLbl.sTexto << _self.sDescripcion
  Después de esta llamada el elemento está listo para renderizar.

── LO QUE NO SE TRANSCRIBIÓ / DIFERENCIAS ─────────────────────────────────────

1. define_shared_constant(:activate_properties_dialog_on_insert?, _false)
   define_shared_constant(:allowed_on_menu?, _false)
   → Metadatos del framework Smallworld. Sin equivalente en React.
     Se documentan como comentario en el fichero .tsx.

2. define_slot_access (slots sNombre_Simbolo, sNombre_Empalme)
   → Estaban comentados en el fuente Magik original. No se transcriben.

3. _super.new(RoObjeto) / herencia de c_elemento_entidad_g
   → La clase padre no está migrada aún. Los slots relevantes
     (sDescripcion, nLongGrafica, oElementos, oArea, collEtiquetas)
     se modelan directamente en ElementoEmpalmeG hasta que se migre
     c_elemento_entidad_g.magik.

4. asigna_valor_etiqueta (método comentado en el Magik original)
   → No se transcribe al estar desactivado en el fuente.

5. Renderizado SVG
   → En Magik el renderizado lo hace el framework gráfico de Smallworld
     internamente (c_simbolo_grafico, c_texto_grafico son clases del fw).
     En TS se reimplementa como SVG: línea + polígono rombo + elemento text.

── FLUJO DE USO ────────────────────────────────────────────────────────────────

  const elem = new ElementoEmpalmeG({ numEmpalme: 42 });
  elem.oArea = { xMin: 0, xMax: 80, yMin: 0, yMax: 80 };
  elem.configurarElementos();
  // → elem.oElementos.Etiqueta_1.texto === "ER-42"
  // → elem.oElementos.Simbolo_1.nombre === "empalme de cobre"

  // O directamente el componente React:
  <ElementoEmpalmeGUI entidad={{ numEmpalme: 42 }} width={80} height={80} />
