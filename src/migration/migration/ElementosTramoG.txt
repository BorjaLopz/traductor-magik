-- QUE HACE -------------------------------------------------------------------

Administra una coleccion de elementos de tramo, calcula la longitud total
(sin empalmes) y el numero de elementos habilitados.

-- METODOS TRANSCRITOS ---------------------------------------------------------

Magik: new()
TS:    ElementosTramoG.create()

Equivalencia:
  - _clone -> new ElementosTramoG()

-----------------------------------------------------------------------

Magik: Longitud_Total()
TS:    ElementosTramoG.longitudTotal()

Equivalencias directas:
  - recorre collElementos
  - considera solo bHabilitar? = true
  - excluye empalmes (is_kind_of? c_elemento_empalme_g)
  - suma nLong_Grafica

-----------------------------------------------------------------------

Magik: Despliega()
TS:    ElementosTramoG.despliega()

Equivalencia:
  - recorre collElementos y llama despliega()

-----------------------------------------------------------------------

Magik: nTotal_Elementos
TS:    ElementosTramoG.totalElementos()

Equivalencias directas:
  - cuenta elementos con bHabilitar = true

-- COMPONENTE REACT ------------------------------------------------------------

ElementosTramoGUI
  - Usa un set mock de elementos.
  - Muestra cantidad habilitada y longitud total.

-- LO QUE NO SE TRANSCRIBIO ----------------------------------------------------

- Integracion con oVentana y oArea por elemento.
- Tipos reales de c_elemento_empalme_g y c_elemento_tramo.
