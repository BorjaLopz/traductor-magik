-- QUE HACE -------------------------------------------------------------------

Construye los titulos y valores de referencia para la tabla PEP.
Se maneja el numero de renglones (3) y se devuelven tres entradas:
  1) DESMONTAJE
  2) CANALIZACION
  3) SECUNDARIO

-- METODOS TRANSCRITOS ---------------------------------------------------------

Magik: dfn_Detalle_Titulo_Referencias()
TS:    PepDcs.dfnDetalleTituloReferencias(): Promise<ReferenciasMap>

Equivalencias directas:
  - _self.nNumero_Renglones << 3  -> nNumeroRenglones = 3
  - hash_table.new()              -> Record<number, string>
  - LcollTitReferencias[1..3]     -> titles[1..3]

-----------------------------------------------------------------------

Magik: dfn_Detalle_Valores_Referencias()
TS:    PepDcs.dfnDetalleValoresReferencias(): Promise<ReferenciasMap>

Equivalencias directas:
  - _if _self.oProyecto.existe? -> if (proyecto)
  - referencia_desmontaje       -> referenciaDesmontaje
  - referencia_canalizacion     -> referenciaCanalizacion
  - referencia_secundarios      -> referenciaSecundarios
  - _else                        -> cadenas vacias por defecto

-- COMPONENTE REACT ------------------------------------------------------------

PepDcsUI
  - Instancia PepDcs con un proyecto mock.
  - Llama ambos metodos y renderiza una tabla titulo/valor.
  - Muestra nNumeroRenglones como metadato.

-- LO QUE NO SE TRANSCRIBIO ----------------------------------------------------

- Integracion con oProyecto real del editor Smallworld.
- Origen de datos de base (solo mock en la demo).
