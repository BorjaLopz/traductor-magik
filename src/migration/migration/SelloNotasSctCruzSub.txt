-- QUE HACE -------------------------------------------------------------------

Crea la tabla de notas generales (2 filas x 1 columna) y asigna un bloque
extenso de texto con reglas del cruce subterraneo.

-- METODOS TRANSCRITOS ---------------------------------------------------------

Magik: prvCrea_Cfg_Tbl_Notas_Grales(RoCoord)
TS:    SelloNotasSctCruzSub.prvCreaCfgTblNotasGrales(origin)

Equivalencias directas:
  - oTablas.crea_tabla(2,1,:tbl_notas_grales) -> TableDefinition con id y tamano
  - oCoordenada_Origen << RoCoord             -> origin
  - renglones[1]=10, renglones[2]=210         -> rowHeights [10, 210]
  - columnas[1]=165                           -> colWidths [165]

-----------------------------------------------------------------------

Magik: prvAsignaTexto()
TS:    SelloNotasSctCruzSub.prvAsignaTexto(table)

Equivalencias directas:
  - _super.prvAsignaTexto() -> baseTexto (opcional) que se antepone
  - character.newLine       -> '\n'
  - concatenaciones con s_tipo_cable, s_estado, s_procedimiento
    -> interpolacion de cadenas
  - oTablas.elemento(:tbl_notas_grales).oCeldas.Celda(2,1).oElemento.sTexto +<< LsTexto
    -> cell (2,1) con texto asignado

-- COMPONENTE REACT ------------------------------------------------------------

SelloNotasSctCruzSubUI
  - Instancia la clase con datos mock.
  - Llama build() (crear tabla + asignar texto).
  - Renderiza el texto de la celda (2,1) en un bloque preformateado.

-- LO QUE NO SE TRANSCRIBIO ----------------------------------------------------

- Integracion con tablas reales de Smallworld.
- Textos de la clase padre (solo se simula baseTexto).
