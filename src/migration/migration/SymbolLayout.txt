-- QUE HACE -------------------------------------------------------------------

Lista los nombres de simbolos disponibles y dibuja una muestra del simbolo
seleccionado, aplicando color y transformaciones (rotacion, flip, mirror).

-- METODOS TRANSCRITOS ---------------------------------------------------------

Magik: symbol_names
TS:    SymbolLayout.symbolNames(): Promise<string[]>

Equivalencias directas:
  - abre_style_sigc + symbol_bundle_table.open(...).symbol_names -> SymbolDataSource.listSymbolNames()
  - sorted_collection -> sort() sobre array de nombres

-----------------------------------------------------------------------

Magik: draw_content_on(window)
TS:    SymbolLayout.drawContentOn(): Promise<DrawResult>

Equivalencias directas:
  - if name unset -> draw_incomplete(select_a_symbol) -> status=incomplete
  - open style view + new_detached_record -> SymbolDataSource.renderSymbol()
  - if actual_geoms unset -> unknown symbol -> status=unknown
  - angle en radianes negativo, flip y mirror -> parametros de render

-- COMPONENTE REACT ------------------------------------------------------------

SymbolLayoutUI
  - Carga lista de simbolos (mock).
  - Permite elegir simbolo, color, angulo, flip y mirror.
  - Renderiza una muestra en SVG.

-- LO QUE NO SE TRANSCRIBIO ----------------------------------------------------

- Acceso real a la base de estilos SIGC y symbol_bundle_table.
- Dibujo real en ventana de layout Smallworld.
