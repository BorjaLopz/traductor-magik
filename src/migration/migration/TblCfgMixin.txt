-- QUE HACE -------------------------------------------------------------------

Mixin de configuracion de bordes para tablas de plotting (sellos).
NO realiza calculo espacial ni interactua con el mapa: opera sobre una
tabla logica con renglones x columnas donde cada celda tiene 4 bordes
(superior, inferior, izquierda, derecha) on/off.

Dos preconfiguraciones de alto nivel:

  cfg_tbl_titulo(tbl)
    - Apaga bordes inf/sup en las 4 cols extremas (1, 2, totCols-1, totCols).
    - Apaga contorno superior segun patron fijo (ren=1, cols 1..5).
    - Apaga contorno inferior segun patron fijo (ren=3, col=3).

  cfg_tbl_detalle(tbl)
    - Apaga bordes inf/sup en las 4 cols extremas.
    - Apaga TODOS los bordes en cols 3..6.
    - Prende contorno de detalle (rectangulo exterior) en cols 3..6.
    - Prende linea inferior en col 5 para renglones interiores (2..totRens-1)
      -> marcado de celdas editables.

Migrado como clase TS con metodos estaticos (mixin sin estado). Se incluye
ademas una clase auxiliar Tabla que modela orenglones, oColumnas y
activa_borde_celda(ren, col, lado).

-- METODOS TRANSCRITOS ---------------------------------------------------------

Magik: cfg_tbl_titulo(pTbl)
TS:    TblCfgMixin.cfgTblTitulo(pTbl)

Equivalencias:
  - totCols << pTbl.oColumnas.total_elementos -> pTbl.oColumnas.totalElementos
  - cols << {1, 2, totCols - 1, totCols}      -> [1, 2, totCols - 1, totCols]
  - apaga_bordes_inf_sup_de_todos_rens_en_cols(tbl, cols)
  - apaga_bordes_a_modo_en_contorno_sup(tbl)
  - apaga_bordes_a_modo_en_contorno_inf(tbl)

-----------------------------------------------------------------------

Magik: cfg_tbl_detalle(pTbl)
TS:    TblCfgMixin.cfgTblDetalle(pTbl)

Equivalencias:
  - cols extremas -> apagaBordesInfSupDeTodosRensEnCols
  - cols {3,4,5,6} -> apagaTodosLosBordesDeTodosRensEnCols
  - prendeBordesDeDetalle(pTbl, [3,4,5,6])
  - prendeLineasDeCeldasEditables(pTbl, [5])

-----------------------------------------------------------------------

Magik: apaga_bordes_inf_sup_de_todos_rens_en_cols(pTbl, pCols)
TS:    TblCfgMixin.apagaBordesInfSupDeTodosRensEnCols(pTbl, pCols)

Equivalencias:
  - totRens << pTbl.orenglones.total_elementos
  - _for ren _over range(1, totRens)
      -> rangeInclusive(1, totRens)
  - _for col _over pCols.fast_elements()
      -> for (const col of pCols)
  - pTbl.activa_borde_celda(ren, col, :superior) << _false
      -> pTbl.activaBordeCelda(ren, col, 'superior', false)
  Idem para :inferior.

-----------------------------------------------------------------------

Magik: apaga_bordes_a_modo_en_contorno_sup(pTbl)
TS:    TblCfgMixin.apagaBordesAModoEnContornoSup(pTbl)

Transcripcion 1 a 1 del patron fijo de 7 sentencias para ren=1, cols 1..5.

-----------------------------------------------------------------------

Magik: apaga_bordes_a_modo_en_contorno_inf(pTbl)
TS:    TblCfgMixin.apagaBordesAModoEnContornoInf(pTbl)

Transcripcion 1 a 1: ren=3, col=3 apaga inferior/izquierda/derecha.

-----------------------------------------------------------------------

Magik: apaga_todos_los_bordes_de_todos_rens_en_cols(pTbl, pCols)
TS:    TblCfgMixin.apagaTodosLosBordesDeTodosRensEnCols(pTbl, pCols)

Equivalente al anterior pero apagando los 4 lados por celda.

-----------------------------------------------------------------------

Magik: prende_bordes_de_detalle(pTbl, pCols)
TS:    TblCfgMixin.prendeBordesDeDetalle(pTbl, pCols)

Equivalencias:
  - ren << 1; renUlt << totRens
  - Para cada col: prende superior en ren=1 y inferior en renUlt
  - colIzq << pCols[1]; colDer << pCols[pCols.size]
      Magik es 1-based -> pCols[0] y pCols[length - 1] en TS
  - Para cada ren en [1..totRens]: prende izquierda en colIzq y
    derecha en colDer.

Efecto: dibuja un rectangulo cerrado alrededor del bloque pCols.

-----------------------------------------------------------------------

Magik: prende_lineas_de_celdas_editables(pTbl, pCols)
TS:    TblCfgMixin.prendeLineasDeCeldasEditables(pTbl, pCols)

Equivalencias:
  - _for ren _over range(2, totRens - 1)
      -> rangeInclusive(2, totRens - 1)
  - Prende inferior en cada celda del rango -> linea separadora entre
    renglones internos (apariencia de campos editables apilados).

-- CLASE AUXILIAR Tabla --------------------------------------------------------

Modela el contrato esperado por el mixin sin importar la tabla real de
Smallworld:
  - orenglones: { totalElementos: number }
  - oColumnas:  { totalElementos: number }
  - activaBordeCelda(ren, col, lado, valor)
  - getBordes(ren, col) -> { superior, inferior, izquierda, derecha }

Indices 1-based para preservar la semantica de Magik (pCols[1] = primer
elemento, pTbl.activa_borde_celda(1, 1, ...) = celda superior izquierda).

-- COMPONENTE REACT ------------------------------------------------------------

TblCfgMixinUI
  - 3 modos: inicial (todos los bordes), cfg_tbl_titulo, cfg_tbl_detalle.
  - Tabla 5 renglones x 8 columnas.
  - Renderiza cada celda en HTML <table> con bordes condicionales:
      borderTop:    superior  ? '2px solid #222' : '2px solid transparent'
      borderBottom: inferior  ? ...
      borderLeft:   izquierda ? ...
      borderRight:  derecha   ? ...
  - Etiqueta de cada celda con (ren, col) para inspeccion visual.

-- LO QUE NO SE TRANSCRIBIO ----------------------------------------------------

- def_mixin de Smallworld -> en TS se usa una clase estatica como contenedor.
  Cualquier clase puede llamar TblCfgMixin.cfgTblTitulo(table) en vez de
  heredar del mixin.
- pragmas (classify_level=advanced, topic={plotting}, usage={subclassable}).
- Render real con line_style.new_with_properties en draw_line_transform
  (aqui se sustituye por bordes CSS).
